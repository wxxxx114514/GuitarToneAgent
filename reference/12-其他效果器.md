# 其他效果器（手动模式）

> **这个主题现在有独立的 skill：`guitar-tone-manual`**
>
> 那份才是正文。这里只留一个指路牌，避免两份内容漂移。

## 为什么拆出去

```
guitar-tone-agent      完整方法论 + GE250 落地（预设是文件 → 全自动）
     └─ guitar-tone-manual   同一套方法，落地换成「出表格 → 用户手动拧」
```

**`guitar-tone-manual` 是这个 skill 的附属** —— 它指向本目录的 `reference/`，
自己不重复方法论，只讲两件 GE250 之外才需要的事：

1. **怎么从说明书/截图整理出设备规格**（`parameter_table.json` + `preset.json` 两文件）
2. **算完之后怎么让用户手动落地**（出「拧到几」的表 + 话术）

## 怎么触发它

目标设备不是 GE250、或者拿不到参数文件接口时，加载 `guitar-tone-manual`。
