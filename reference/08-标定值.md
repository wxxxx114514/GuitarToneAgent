## 0. 一句话总览

```
尺子 = 「每个旋钮动 1 个单位，13 段各变多少 dB」
本机噪声 σ = 0.078 dB  ->  任何小于 0.1 dB 的差别都是噪声
EQ 五段每值单位 0.2166~0.2579 dB（值域 0~64 = ±16 dB）
AMP 四旋钮每值单位 0.0535~0.1215 dB（满量程 5.4~12.15 dB）
CAB Center 0.0560 dB/单位（完全线性）· CAB Distance 改整体电平 ~0.12 dB/单位
FXA Ratio 单调（−0.11 dB/单位）· Thres 非单调 · Attack 无效 · Level 纯电平
时间维（H11）：回声间隔 ≈ Time 值 · 回声低 22.5 dB · RT60 ≈ 1.15 s · 指纹 0.84/0.50 · ac@500ms +0.28/−0.12
```
