## ★★ 用 uv 建环境（克隆之后跑这一条）

```
uv sync        # 读 pyproject.toml + uv.lock -> 建 .venv
```

| | |
|---|---|

| `uv.lock` | 锁版本（65 个包，含 scipy / numba / sympy 等传递依赖）|
| `.venv` | `uv sync` 生成 · **不进仓库**（`.gitignore` 已挡）|

★ **一次 `uv sync` -> 流程 + 分轨全都能跑** —— 不用再建"最小环境"。
★ 这 63 个里**包含**流程本身要的那 3 个：**numpy 2.5.3 · soundfile 0.14.0 · librosa 1.0.0**（版本一模一样）。

## ★★ 分轨模型（667 MB · 不进仓库 · ★ 可选）

★★ **先说结论：它不是这条流程的硬依赖。**
　阶段 2 步 2.0 要的只是【**参考曲分轨**】这个**输入** —— 分轨怎么来的，流程不管（**就两种**，见下）。

**两条路（就这两种）**

```
① 现成的          -> 直接用
                     ★ 本轮就是这条：温度差\guitar.wav 是既有的，模型一次没跑

② 模型分轨         -> 跑模型出分轨
                     python <本项目>\tools\dl_bsr.py            # 下模型到 <本项目>\models\（667 MB）
                     python <本项目>\tools\dl_bsr.py --check    # 只校验已有文件
                     python <本项目>\tools\load_bsr.py <歌> <出>  # 跑分轨
                     （模型 = HuggingFace Blakus/bs_roformer_sw_6stem · 断点续传 + 代理切换 + sha256 校验）
                     ★ **只有这个模型能用**（用户口径）：别的（UVR / demucs）**质量不够 -> 拒绝**
                       —— 分轨质量直接决定【目标】，所以就只用这一个（BS-Roformer SW 6-stem）
```

★ **仓库里不带【权重】**：667 MB（BS-Rofo-SW-Fixed.ckpt）—— 靠 dl_bsr.py 下载 + sha256 校验。
★ **两个小文件是入库的**（在同一仓库的 `<本项目>\models\`）：
　 　MANIFEST.json（来源 + 字节数 + sha256）· BS-Rofo-SW-Fixed.yaml（4.9 KB 配置）—— 复现必需。
★ **为什么不用 Git LFS**：667 MB；GitHub 免费 LFS 只有 1 GB 存储 / 月 1 GB 带宽 —— 一个人 clone 就用掉大半。
★ **来源**：HuggingFace `Blakus/bs_roformer_sw_6stem` @ `dd755f5f`（GitHub 上同名仓库是 404，实际只在 HF）。
★ 三件一起才叫"可复现"：**地址 + commit + sha256** —— 缺一个都不敢说下到的是同一个文件。
★ 本轮状态：**模型一次没跑** —— 分轨是现成的；`load_bsr.py` / `dl_bsr.py` 都标 ⚪（见 11-工具清单）。

## 三、音频链路事实

```
★ AUDIO MODE 必须是 REAMP（NORMAL 模式回传收不到效果链输出）
   断电会重置 -> 每次上机确认；若已是 REAMP，点一下 NORMAL 再点回 REAMP 强制下发
★ 采样率：统一 48 kHz（跟设备）；目标分轨重采样到 48k
★ 端点：设备名含 MOOER（输入 线路(MOOER STUDIO) · 输出 扬声器(MOOER STUDIO)）
   WinMM 实测：in#0 / out#3
★ 发送格式：48k / 2ch / 16bit（不是就拒收）
★ 设备文件名只能 A-Za-z0-9
```
