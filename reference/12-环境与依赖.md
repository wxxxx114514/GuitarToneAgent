## ★★ 用 uv 建环境（克隆之后跑这一条）

```
uv sync        # 读 pyproject.toml + uv.lock -> 建 .venv
```

| | |
|---|---|
| `pyproject.toml` | 本 skill 的环境定义 —— **只有 3 个依赖**：numpy 2.5.3 · soundfile 0.14.0 · librosa 1.0.0 |
| `uv.lock` | 锁版本（27 个包，含 scipy / numba 等传递依赖）|
| `.venv` | `uv sync` 生成 · **约 310 MB · 不进仓库**（`.gitignore` 已挡）|

★ **传的是 lock，不是环境** —— 别人 `uv sync` 就有一模一样的库。
★ 实测：`uv sync` -> `.venv\Scripts\python.exe` 跑 `make_send.py` 与 `do_reamp.ps1` 都通过。
★ **要跑分轨模型**（torch / audio-separator，约 2.5 GB）-> 用 **`<包根>`** 的 `pyproject.toml` + `uv.lock`，
　 那边是完整的 66 个依赖。本 skill 这份是**最小集**，只够跑这 3 个驱动。

### 唯一要指的 = 【Python 解释器】。四选一

```
① 用包自带入口（★ 最省事 · 零配置）
     <包根>\tone.bat env              # 检查环境（Python / 依赖 / 模型 / ffmpeg）
     <包根>\tone.bat run <包内脚本>     # 跑任意包内脚本
   ★ tone.ps1 还会【自愈】：venv 的 pyvenv.cfg 里 home 是绝对路径，包搬家后会失效
     -> 它自动改回 <包根>\python
   ⚠️ tone.bat 的退出码恒 0 —— 只能当"跑脚本"的入口，不能当判据门

② 加进 PATH（一次）      setx PATH "%PATH%;<包根>\venv\Scripts"
③ 设环境变量（一次）      setx TONE_PY "<包根>\venv\Scripts\python.exe"
④ 每次写全路径            <包根>\venv\Scripts\python.exe <包内脚本>
```

## ★★ 分轨模型（667 MB · 不进仓库 · ★ 可选）

★★ **先说结论：它不是这条流程的硬依赖。**
　阶段 2 步 2.0 要的只是【**参考曲分轨**】这个**输入** —— 分轨怎么来的，流程不管（**就两种**，见下）。

**两条路（就这两种）**

```
① 现成的          -> 直接用
                     ★ 本轮就是这条：温度差\guitar.wav 是既有的，模型一次没跑

② 模型分轨         -> 跑模型出分轨
                     python <包根>\tools\dl_bsr.py            # 下模型到 <包根>\models\（667 MB）
                     python <包根>\tools\dl_bsr.py --check    # 只校验已有文件
                     python <包根>\tools\load_bsr.py <歌> <出>  # 跑分轨
                     （模型 = HuggingFace Blakus/bs_roformer_sw_6stem · 断点续传 + 代理切换 + sha256 校验）
                     ★ **只有这个模型能用**（用户口径）：别的（UVR / demucs）**质量不够 -> 拒绝**
                       —— 分轨质量直接决定【目标】，所以只用包内这个（BS-Roformer SW 6-stem）
```

★ **仓库里不带【权重】**：667 MB（BS-Rofo-SW-Fixed.ckpt）—— 靠 dl_bsr.py 下载 + sha256 校验。
★ **两个小文件是入库的**（在同一仓库的 `<包根>\models\`）：
　 　MANIFEST.json（来源 + 字节数 + sha256）· BS-Rofo-SW-Fixed.yaml（4.9 KB 配置）—— 复现必需。
★ **为什么不用 Git LFS**：667 MB；GitHub 免费 LFS 只有 1 GB 存储 / 月 1 GB 带宽 —— 一个人 clone 就用掉大半。
★ **来源**：HuggingFace `Blakus/bs_roformer_sw_6stem` @ `dd755f5f`（GitHub 上同名仓库是 404，实际只在 HF）。
★ 三件一起才叫"可复现"：**地址 + commit + sha256** —— 缺一个都不敢说下到的是同一个文件。
★ 本轮状态：**模型一次没跑** —— 分轨是现成的；`load_bsr.py` / `dl_bsr.py` 都标 ⚪（见 11-工具清单）。

## 三、音频链路事实

```
★ AUDIO MODE 必须是 REAMP（NORMAL 模式回传收不到效果链输出）
   断电会重置 -> 每次上机确认；若已是 REAMP，点一下 NORMAL 再点回 REAMP 强制下发
★ 采样率：统一 48 kHz（跟设备）；目标分轨重采样到 48k
★ 端点：设备名含 MOOER（输入 线路(MOOER STUDIO) · 输出 扬声器(MOOER STUDIO)）
   WinMM 实测：in#0 / out#3
★ 发送格式：48k / 2ch / 16bit（不是就拒收）
★ 设备文件名只能 A-Za-z0-9
```
