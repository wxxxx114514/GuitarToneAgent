# 03 · 算法（每个数怎么算）

> **这份是「换设备也不变」的第三根支柱**：把流程里出现的每一个数，写成**可重算的公式**。
> 每条给：**公式 · 输入 · 输出 · 本轮数值 · 来源**。数值只是例子；公式才是资产。
> 数值纪律：来源四档 = 实测 / 换算 / 我定 / ⛔待定（见 04-判据与来源）。


> ★ **与设备的关系**：**公式整份不绑设备**；文中的数值只是例子（GE250 的）。

## 一、基础量（所有比较的公共底座）

### 1.1 13 段（√2 划分）

```
边界：每段 = 上一段 x sqrt(2)，从 80 Hz 起
 B1 80-113 · B2 113-160 · B3 160-226 · B4 226-320 · B5 320-452 · B6 452-640 · B7 640-905
 B8 905-1280 · B9 1280-1810 · B10 1810-2560 · B11 2560-3620 · B12 3620-5120 · B13 5120-7240
中心频率：95 134 190 268 380 537 761 1076 1522 2152 3044 4305 6088

算法（逐段）：
  ① 对信号做 STFT
  ② 把该段频率范围内所有 bin 的【功率】求和（不是取最大、也不是取平均）
  ③ 转 dB：10*log10(P)      <- ★ 标准 dB（同段幅度 x2 -> +6.02 dB）
  ④ 得到 13 个数 -> 跨 13 段【去均值】（这样只比「形状」，不受响度影响）
```

★ **本轮口径（复现必须一致）**：**Nf = 16384 · hop = 8192 · Hann 窗**（源：h4_step.py / h1_step.py … 的 env13）。
　⚠️ 见过有实现用 8192 / 4096 —— **不是本口径**，两者分辨率不同。**口径以本行为准。**
- **输入**：任意 wav（目标轨 / 湿声 / DI）
- **输出**：13 个去均值 dB
- **本轮数值**：目标 = −6.92 −23.43 −8.19 −6.45 11.07 9.30 5.64 3.38 4.84 6.87 7.00 2.07 −5.18

### 1.2 短时动态（P95 − P50）

```
① 以 20 ms 为一帧，算每帧 RMS（dB）
② 取所有帧 RMS 的 P95 与 P50
③ 短时动态 = P95 - P50（dB）
★ 百分位用 numpy 默认的【线性插值】口径（不是取整索引）
```

- **为什么**：时均看不见动态，短时看得见。
- **本轮数值**：目标 **2.03 dB** · 无 FXA 21.36 · FXA 基准 11.95
- **来源**：实测（M15，定为判据）
- ★ **失效条件**：**必须同素材** —— 同一预设，送「第一段 DI」= 21.56，送「目标段 DI」= 0.53（差 21 dB）

### 1.3 crest（峰值因子）

```
crest = peak(dBFS) - RMS(dBFS)      （本轮：整段算一次）
```

- **本轮数值**：目标 **12.45 dB** · 起点 13.23 · 终态 13.15
- **来源**：实测（M15）

### 1.4 削顶

```
削顶样本 = 满足 abs(x) >= 0.999 且【连续 >= 3 个样本】的位置
削顶数 = 0 -> 过
```

- **来源**：**我定**（统一旧项目四套标准；本轮实测 −48~−16 dBFS 全为 0）
- **推翻记录**：设计期是「峰值 >= −0.1 报警 · 占比 > 0.1% 判死」-> 换成本式（15 §4.2）
- **注**：设备内部还有**限幅 / 饱和**（回录峰渐近 ≈ −1.1 dBFS），那不是数字削顶

### 1.5 内容匹配（形状相关）—— ★ 已降为「自检」

```
① 两段素材各自算 13 段（去均值）
② 算 Pearson 相关
用途：★ 只作【自检】（判「我拿到的两段是不是同一段」）
      ★ 不再是硬门（不再「必须 > 0.4 才开工」）
```

- **本轮数值**：**0.482**（可用）
- **来源**：实测 0.482
- ★ **必须裁空白 + 时长归一**，否则假匹配（未裁空白 0.030 / 滑窗假匹配 0.939）
- ★ **定案**：降为自检、删硬门 —— 理由：它有用（本轮真的发现了「用户录的那份 DI 对不上 9~17s」），
　但「> 0.4 才继续」会挡住不该挡的（15 §5-3 定案）。

## 二、标定量（建「尺子」用的算法）

### 2.1 H7 · 重复性 σ

```
① 三种动作各做录音：连录 x2 · 切走再切回 x2 · 跨一次
② 每一对录音，算它们 13 段的差 d
③ σ = sqrt( mean(d^2) )（dB）
```

- **本轮数值**：连录 0.0780 · 切走再切回 0.0240 · 跨一次 0.0853 -> **σ = 0.078 dB**
- **判据**：σ < 精度/3（精度 0.3 是**我定**）-> 0.078 < 0.1 ✓
- **来源**：实测（账本 #15）
- **推翻记录**：设计期判据是「σ >= 0.022 dB -> 停」（0.022 是编的）-> 改成 0.1（账本 #119）
- ★ **它是所有其它判据的标尺**：任何小于 σ 的差别都是噪声 -> 见 04

### 2.2 H4 · EQ 每值单位（★ 名字坑）

```
① 对某一段单独 +N 个值单位、-N 个值单位，各录一次
② 看该段峰值频段的 dB 变化
③ 对该频段做线性拟合 -> 每【值单位】的 dB

★★ 命名陷阱（我混过一次）：
   标定文件里那个字段 per_unit_db_at_peak 实际是【每 1 dB 频段增益的峰值效应】
   每【值单位】= 它 x 0.5
   例：100Hz 段 0.5157 -> 每值单位 0.2579（因为 1 值单位 = 0.5 dB 频段增益）

★★ 值域映射：EQ 段 0~64 对应 −16~+16 dB
   dB = (值 - 32) x 0.5      32 = 0 dB · 52 = +10 dB · 12 = -10 dB
```

- **本轮数值**（每值单位，dB/值单位）：100Hz **0.2579** · 250Hz **0.2431** · 630Hz **0.2166** · 1.6KHz **0.2275** · 4KHz **0.2539**
- **来源**：实测 + 换算（账本 #58 #62 #76 #244）
- **复算**：从 H4响应矩阵.csv 的 eq01~eq05 峰段重算 -> **5/5 一致** ✓
- ★ **型号必须写清**：以上是 **MOOER G**（Type 0）的。包旧文档里那套（零点 50 / 范围 0-100 / 每单位 0.185 / 高斯 σ=0.985 八度）是 **5-BAND** 的 —— **两者都对，但不能混**（见 07 §二）

### 2.3 H4 · 叠加残差（能不能线性叠加）

```
① 五段各自单独 +N -> 得到五个响应向量
② 五段同时 +N -> 得到合成响应向量
③ 叠加残差 = RMS(合成 - 五段之和)
判据（我定）：残差 < 0.5 dB 才算可线性叠加
```

- **本轮数值**：残差 RMS **1.259 dB** -> **不可线性叠加 -> 解 EQ 必须迭代**；单次改动上限 **<= 10 dB**（我定）
- **来源**：实测 + 我定（账本 #64 #65）· **复算 1.2592** ✓
- **实证**：步 8 五段同降时，实测幅度普遍小于标定预期（B1 预期 −0.52 / 实测 −0.02）

### 2.4 H4 · 对称性

```
对某段：分别 +N 与 -N，得到两个响应
对称残差 = RMS(响应(+N) + 响应(-N))        （完全对称时应为 0）
```

- **本轮数值**：630Hz **0.023**（完美）· 100Hz **0.734**（不对称）
- **来源**：实测（账本 #57 #61）· **复算 2/2 一致** ✓
- **用法**：不对称的段 -> 分方向用（升 / 降分别查表）

### 2.5 H4 · 段间可分性

```
① 五段响应向量两两算相关
② 去共线（把其它段的影响回归掉）后的残差
判据（换算）：残差 > σ 才算可分
```

- **本轮数值**：去共线残差最小 **1.629** >> σ 0.078 -> **五段全部可分**
- **相关**：标定文字写「最高 **0.7478**」—— ⚠️ **我从矩阵复算不出**（我算绝对值最大 0.7531 / 有符号最大 0.5279）。
　★ **口径在 _redo\h4_corr2.py**（它的自述：「H4 各点两两相关 + 去共线残差 + 形状」）；复现前先读那个脚本。
- **来源**：实测 + 换算（账本 #54）

### 2.6 H1 · AMP 多旋钮（L9 正交）

```
① 三旋钮各三水平，按 L9 正交表布 9 个点
② 对每个 13 段频段，用最小二乘解：
     响应 = 基线 + Σ(主效应_i x 水平_i) + Σ(交互项_ij x 水平_i x 水平_j) + 残差
③ 输出：每旋钮每值单位 dB（主效应）· 交互项 · 全模型残差 RMS
④ 第四旋钮（Pres）单独多点，看线性
```

- **本轮数值**：Bass 峰 B1 **+0.1215** · Mid 峰 B6 **+0.0754** · Treble 峰 B13 **+0.0744** · Pres 峰 B12 **+0.0535**
- **交互项**：最大 0.044 dB，占主效应 2.43 的 **1.8%** -> 三旋钮基本独立，可连续用
- **全模型残差**：RMS **0.0103 dB**（< σ/7）-> 线性模型够用
- **满量程**：12.15 / 7.54 / 7.44 / 5.4 dB（换算 = 每值单位 x 100）
- **来源**：实测 + 换算（账本 #154）· **复算 3/3 一致** ✓
- ★ **Bass 非线性**：降 20 单位 −3.29 dB / 升 20 单位 +2.03 dB -> **降比升强，两侧分别用**

### 2.7 H2 · CAB 两参数

```
Center：扫 5 点 -> 线性拟合 -> 每值单位；再看「完全线性」是否成立
Distance：扫 5 点 ->
   形状 = 13 段的【去均值】响应（看它改不改形状）
   总电平 = 【回录峰】的变化（看它改不改响度）      <- ★ 不是 13 段的均值（去均值后恒为 0）
★ 另外必做「零变化对照」：同一设定录两次，看噪声底
```

- **Center**：峰 B13 **+0.0560/单位**（完全线性，满量程 5.6 dB，五点 +1.07/~0/−1.12/−2.25/−3.38）· **复算逐点一致** ✓
- **Distance**：形状 0.035~0.052（离散 33%）· **总电平 ~0.12 dB/单位**
- ⚠️ **满量程口径（已定案）**：**10→90 实测 9.61 dB**（峰 −1.48 -> −11.09）· **外推 0→100 ≈ 12.0 dB**。
　（原写「11.5 dB」= 0.115 x 100，取的是区间下界 —— 口径不统一；**以 9.61 / 12.0 为准**）
- **零变化对照**：最大 0.06 · 均值 0.03 dB（验证测量稳定 + 加载正确 + 信噪比 13 倍）
- **来源**：实测（账本 #116 #161 #167 #168）

### 2.8 H3 · FXA（压缩类）—— ★ 两套 dyn 口径

每个参数扫 3 点；每点量：峰(dBFS) · 短时动态 P95-P50 · crest

## 三、对齐（比较的前提）

### 3.1 找 lag（FFT 互相关）

```
① 只取【有辨识度】的段（本轮：前 3 秒，避开重复乐句）
② 全范围 FFT 互相关（不是从 0 截断）
③ 取相关峰的位置 -> lag（样本）
```

- **本轮数值**：三版湿声各自 lag −85.75 / −91.88 / −87.77 ms
- ★ **同一次播放/录音的不同设置版本 -> 必须用【同一个对齐偏移】**（统一 lag）
- **来源**：实测（M30，铁律）

### 3.2 估增益（RMS 比）

```
取对齐后的一段（本轮：前 1.5~2.5 s）
g_dB = 20*log10( RMS(cand) / RMS(ref) )
```

- **为什么不用最小二乘**：逐点最小二乘在微小错位时会崩（实测给过 −28.76 dB）
- **来源**：实测（M30，铁律）

## 四、闭环（B 组用的算法）

### 4.1 残差

```
残差_b = 湿声13段_b - 目标13段_b        （两者都已去均值）
```

- **本轮数值**（起点 presetB）：−0.59 +21.74 +6.99 +1.58 −0.11 −6.32 +1.17 −3.57 +0.27 −2.48 −6.86 −3.93 −7.88

### 4.2 WMAE（本轮的判据量）

```
WMAE = mean( abs(残差_b) )      对 13 段求平均
★ 本轮所有 WMAE 都标【不含 B2】—— 因为 B2 是内容差，永远修不掉
★ 权重：本轮用【等权】
```

- **本轮数值**：起点 **3.48** -> SM57 3.03 -> Bass34/Mid70 2.98 -> EQ 2.85（地板）
- **口径说明**：另有「按地板 / 可行动空间加权」的版本，**本轮未采用** -> ⚪ 未验（本轮用等权）
- **来源**：实测（账本 #243 #254）

### 4.3 内容差（★ 决定地板）

```
内容差_b = 源头DI_13段_b - 目标13段_b
（源头 DI = 用户弹的那段；两者同算法、同素材）
```

- **本轮数值**：−5.92 **+22.04** +6.54 +6.49 +12.05 +5.26 +7.00 −2.04 +2.66 −6.03 −12.58 −12.52 **−22.95**
- ★ **口径（两套都能算出来，差在【输入】）**：本行 = env13(**发送信号 sendTarget.wav**) − env13(目标)（账本 **#194** · 脚本 b13_check.py）；
  08 §9 用的是【用户 DI 的 13 段】− 目标 = −6.06 … −23.14（target_metrics.json::user_di.diff_db）。
  差在哪：发送信号是【裁空白 + 归一化】后的，而 13 段是**全段平均** —— 裁空白会改变参与平均的帧。引用时必须写明口径（见 04 §三）。
- **读法**：B2 源头多 22 dB · B13 源头少 23 dB -> **这两类和它们所在段不追**
- **来源**：实测（M21，关键 · 账本 #194 #195）

### 4.4 成片映射（步 6 用，替代最小二乘）

```
① 先把【内容差段】剔掉
② 把 13 段按旋钮管区分片：
     Bass -> B1~B4 · Mid -> B5~B8 · Treble -> B10~B13 · Pres -> B12~B13
③ 每片的【残差均值】-> 需要的变化量
④ 除以该旋钮的【每值单位】-> 值单位数
⑤ 夹到一次改动上限内（AMP：±40 值单位，我定）
```

- **本轮结果**：Bass 50->34（−16 单位）· Mid 30->70（+40 单位）· **Treble / Pres 不动**
- **为什么不用最小二乘**：出过 **+778 单位**（荒谬）
- **来源**：权威 + 实测（账本 #174 #210）

### 4.5 窄度与窄坑贡献（步 5 用）

```
窄度 narrowness = RMS( v - smooth(v, 3) ) / RMS(v)
    v = 13 段残差向量；smooth(.,3) = 3 点滑动平均
窄坑贡献 = WMAE(原始残差) - WMAE(3段平滑后的残差)
判据（我定）：贡献 < 0.5 dB -> 窄坑不重要 -> 跳过步 7
```

- **本轮数值**：窄度 0.626；**窄坑贡献 0.43 dB**（3.48 -> 3.05）-> **跳过步 7**
- **校准**：纯倾斜 -> 0.0349（权威端点 0.035 ✓）· 单段 6dB 坑 -> 0.8165（权威 0.637，**我偏大 28%**）
- **来源**：实测 0.43 + 我定 0.5（账本 #185 #187）；**窄度定义在大值端偏大 28% -> ⛔待复核**（见 04）

## 五、时间维（H11 用的算法）

| 量 | 公式 / 做法 | 本轮数值 |
|---|---|---|
| **相邻帧跳变中位** | 尾巴段按 10 ms 分帧，算相邻帧 RMS 差，取中位 | DELAY **0.77~0.97** · REVERB **0.45~0.56** |
| **ac@500ms** | **整段**信号的归一化自相关，取 lag = 500 ms 处（★ **必须写清「整段」**：窗口不同值会差到 0.99；不去均值 / 去均值一样） | 干 **−0.133** · DELAY **+0.271** · REVERB **−0.134** |
| **周期性** | 自相关在周期倍数处的凸起强度 | 干 1.07 · DELAY **1.36** · REVERB 1.09 |
| **回声间隔** | 残差（湿 − g·干）的自相关，在 30 ms~1.6 s 找局部峰 | ≈ Time 值（Time=460 -> 实测 451~500，细扫 **499**）|
| **回声水平** | 回声（尾巴峰）与直达声的电平差 | ≈ **22.5 dB 低**（Level=40）|
| **RT60（粗估）** | 按「+800 ms 相对尾巴最大」的衰减率外推 60 dB | ≈ **1.15 s**（Decay=50）|
| **尾巴 RMS** | 干音结束点 +0.2 s 起的 10 ms 帧包络 | 纯延迟 −59.5 · 纯混响 −71.3 · 都开 −59.5 |
| **干路增益** | 湿（只开一个模块）与送出干音的电平差 | **≈ +6.9 dB**（DELAY 6.76 / REVERB 6.97）|
| **留白长度** | 信号结束到录音尾的静音时长 | sendTarget 2.19 s · 目标段 **0.02 s** |

- **来源**：实测（M23~M25 / M30~M33 · 账本 #287 #316 #321）
- ★ **能量层面近似线性叠加**（都开 −59.5 vs 纯延迟 −59.5，差 0.6 dB）；但**逐点** corr 只 0.72（随机相位）-> 线性要看能量 / 统计量
- ★ **ac@500ms 的口径已实测钉住**（2026-10 复核）：**整段**。换成末 1.5 / 2 / 3 / 4 s 窗，DELAY 会从 **+0.271** 变成 +0.013 / +0.091 / **+0.866** / **+0.994** —— 所以**必须写清「整段」**（复算见 15-设计演化 §八）。

- ★ **判据的失效条件**：混合里判不出弱的那个（REVERB 比 DELAY 弱 12 dB）；需要素材有**尾部留白**

## 六、本轮所有「我定」的算法性参数（集中一处，便于复核）

| 参数 | 值 | 为什么 |
|---|---|---|
| 发送电平 | −32 dBFS | 在实测安全区内，信噪比好 |
| 削顶定义 | abs(x) >= 0.999 且连续 >= 3 样本 | 统一旧项目四套标准 |
| 重复性通过线 | σ < 0.1 dB | = 目标精度 0.3 的 1/3 |
| EQ 可线性叠加线 | 残差 RMS < 0.5 dB | 实测 1.259 -> 不可 -> 必须迭代 |
| EQ 单次改动上限 | <= 10 dB | 防撞内部限幅 |
| AMP 单次改动上限 | ±40 值单位 | AMP 只有 0.12 dB/单位，风险小 |
| 窄坑「不重要」线 | 平滑前后 WMAE 差 < 0.5 dB | 实测 0.43 |
| 停手 | 单轮增益 < 死区 / 离地板 ~0.05 dB | 权威 + 实测地板 |
| 内容匹配 | **降为自检**（不作为硬门）| 定案（15 §5-3）|
