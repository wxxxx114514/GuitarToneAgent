### 5.2 FXA = 滤波参量带 -> 实际是压缩器

```
设计：FXA 是 Position / Q / Peak 参量带，用来修窄坑；H3 的目的是测「Q 上限」
实测：FXA = YELLOW COMP 压缩器，参数 = Thres / Ratio / Attack / Level
=> 「窄凹陷可连续修（99%）」作废；H3 的标定内容整体换成「四参数 -> 动态 / crest」
```
