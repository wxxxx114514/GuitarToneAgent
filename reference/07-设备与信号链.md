## 一、参数范围

```
★ 除 EQ 5 段的增益外，其它参数范围都是 0 ~ 100
★ EQ 段增益：0 ~ 64  对应  -16 dB ~ +16 dB
     映射：dB = (值 - 32) x 0.5
     0 = -16 dB · 32 = 0 dB · 52 = +10 dB · 64 = +16 dB
★ Type 编号是 0-based（实测：presetB 里 AMP Type=6 对应手册第 7 个 J800）
```

## 三、★★ 字段名（从真机预设核对 —— 权威）

### 3.1 ★ 真实 .mo 的结构（一手，解析自 presetB.mo）

```
root            = { Capture · CtrlSet · Exp · Merge · Others · effectChain · effectModule · fileInfo }
effectModule[X] = { Data · Switch · Type }          （★ FX LOOP 例外：只有 { Data · Switch }，无 Type）
Others          = { BPM · Delaytime_1 · Delaytime_2 · FxAtime · FxBtime · LedColor · Volume · pVersion }
fileInfo        = { app · app_version · copyright · device · device_version · name · schema }
                 例：device = "MOOER GE250" · app = "GE250 Edit" · schema = "GE250 Preset"
```

### 3.2 各模块 Data 里的真实字段名

```
AMP       Bass · Gain · Mid · Mst · Pres · Treble
CAB       Center · Distance · Level · Mic · Sync · Tube
DS/OD     Gain · Tone · Volume
EQ        1.6KHz · 100Hz · 250Hz · 4KHz · 630Hz · Level
DELAY     F.Back · Level · Sub D · Time                    （★ 无 Thres）
REVERB    Decay · Level · Pre delay · Tone                  （★ 无 Length）
FXA       Attack · Level · Ratio · Thres                    （★ 不是 Q/Peak/Position！）
FXB       Depth · Level · Rate
NS GATE   Attack · Release · Thres
FX LOOP   Dry/Wet · Loop Mode · Return Level · Send Level
TONE CAP  SourceSync
```

### 3.3 ★★ 两处「转述错」—— 别照着抄

| 来源 | 它说 | 真实预设说 | 判定 |
|---|---|---|---|
| **mapping.json**（它自己写着「预设字段名为准」）| FXA = Level / Peak / Position / Q | **FXA = Attack / Level / Ratio / Thres** | ✗ **mapping.json 错** |
| **mapping.json** | NS GATE = 只有 Thres | **NS GATE = Attack / Release / Thres** | ✗ **mapping.json 错** |
| parameter_table.json | 多个参数范围「待确认」| —— | ⚠️ 它是**手册抽取草案**，不是可用参数表 |
| mapping.json | 其余模块（AMP / CAB / DS-OD / EQ / DELAY / REVERB / FXB / FX LOOP / TONE CAP）| **全部一致** ✓ | —— |

★ **教训**：连设备库里的 mapping.json 都会错（它就是设计期按"FXA 是滤波参量带"写的残留）。
　**字段名一律以真机导出的 .mo 为准**（见 13-两表规范 · 10-陷阱清单 坑 11）。

  DS/OD -> AMP -> CAB -> NS GATE -> FXA -> EQ -> DELAY -> REVERB -> SEND -> RETURN -> FXB

## 六、环境 / 链路事实

```
★ REAMP 模式：AUDIO MODE 必须是 REAMP
   （NORMAL 模式回传收不到效果链输出 -> 「录回来 ≈ 送出」，会被误判成「设备无效果」）
   断电会重置 -> 每次上机都要确认；若已是 REAMP，点一下 NORMAL 再点回 REAMP 强制下发
★ 采样率：统一 48 kHz（跟用户设备）· 目标分轨重采样到 48k
★ 音频端点：设备名含 MOOER（输入 线路(MOOER STUDIO) · 输出 扬声器(MOOER STUDIO)）
   WinMM 实测：in#0 / out#3
★ 旁通回传有 +6 dB 固定增益
★ 设备内部有限幅 / 饱和（回录峰渐近 ≈ −1.1 dBFS）—— 那不是数字削顶
★ ★ 界面 != 状态：浏览某个模块时界面会点亮它 -> 状态一律以【导出的预设文件】为准
★ ★ 设备文件名只能 A-Za-z-0-9：下划线 / 空格 / 中文 一律读不了
     ✗ preset_A_Mst60.mo   ✓ presetA60.mo
```
