## 5. 两层指标架构（核心设计）

**参考音频和渲染输出的【内容不同】，所以不能直接逐帧比较。必须分两层：**

```
┌─ 外层（对参考）─────────────────────────────┐
│ 参考 vs 渲染：内容不同、奏法可能不同          │
│ 指标：时均包络（1/3 或 1/6 倍频程）           │
│       × JND权重 × 可行动性 × 地板惩罚         │
│ 作用：定方向、判"这个维度榨干了没有"          │
│ 盲区：混响（时均把它平均掉了）                │
└──────────────────────────────────────────────┘
┌─ 内层（候选之间）───────────────────────────┐
│ 同一个干声过不同预设：内容完全相同 ✓          │
│ 指标：LSD / LogMelMSE / MCD / SC / MultiRes  │
│ 对齐 lag（= 群延迟）当伪影哨兵                │
│ 作用：雅可比 J、伪影检测、精调                │
│ 优势：混响【可见】，对跑偏极敏感              │
└──────────────────────────────────────────────┘
```

### 5.1 逐帧指标的实测灵敏度

以 J900R原版为基准（同一干声）：

| 候选 | LSD | LogMelMSE | MCD | SC | MultiRes |
|---|---|---|---|---|---|
| EQFIX1 | 10.66 | 1.10 | 208.8 | 0.163 | 5.04 |
| EQFIX2 | 12.87 | 1.97 | 213.7 | 0.166 | 5.29 |
| **FIX3** | **20.37** | **8.38** | **562.1** | **0.308** | **8.04** |
| 倍数 | 1.58× | **4.24×** | 2.63× | 1.85× | 1.52× |

**5/5 个指标都把有问题的 FIX3 判出来了**（而时均包络只差 0.29 dB）。

### 5.2 混响在逐帧指标里是可见的

同一个干声，一个过混响预设一个没过：

| 指标 | 时均包络 | LSD | MCD |
|---|---|---|---|
| 数值 | **0.47 dB** | 6.04 | 79.6 |

**时均看不见，逐帧看得见。** 所以：**内层用逐帧，混响自动纳入优化；外层要用混响，得靠独立的 `reverb: {rt60, tail_ratio}` 块。**

## 6. 误差向量与加权

### 6.1 结构

```
e(f) = 目标包络(f) − 实测包络(f)          （外层用）
e_frame = 逐帧指标向量                     （内层用）
```

### 6.2 分解：地板 vs 可行动

**方法：在参数空间采 N 个点，看误差向量的统计量。**

```python
地板     = mean(e_i)     # 不随参数变化 → 源差异 + 内容差异，修不掉
可行动   = std(e_i)      # 随参数变化   → 真正的优化空间
```

**实测（4 个预设）：**
```
地板 RMS   1.36 dB
可行动 RMS  0.62 dB
```

**各版本位置：**
| 版本 | 总误差 | 地板分量 | 可修正分量 |
|---|---|---|---|
| J900R原版 | 1.77 | 1.56 | 0.85 |
| EQFIX1 | 1.40 | 1.37 | 0.28 |
| **EQFIX2** | 1.23 | 1.20 | **0.26** ← 贴到地板了 |
| FIX3 | 1.52 | 1.31 | 0.77 ← 跑开了 |

**停止判据：单轮增益 < 0.1 dB（见 §9.2），不是总误差 < 阈值。**

**⚠️ 采样点必须【分散】，不能沿同一个方向采。**
只在一条线上采（比如只调 EQ），算出的"可行动"会被**系统性高估**——
因为它测的只是那一个方向的变化量。
**几个维度各动一动**（EQ / 增益 / 压缩），采样矩阵才代表参数空间。

### 6.3 频段加权

```python
w(f) = JND权重(f) × 可行动性(f) × 地板惩罚(f)
# JND权重: 1/jnd(f)，500Hz-5kHz 最敏感
# 可行动性: std(e)/(mean(std))  —— 参数能改变的幅度
# 地板惩罚: 1/(1 + (|mean(e)|/std(e))²)  —— 地板大说明修不了
```

**实测权重（存于 `band_weights.npy`）：**
```
 761 Hz   地板 +2.46  可行动 0.20  →  权重 0.006   （修不了，忽略）
4305 Hz   地板 −0.11  可行动 1.06  →  权重 4.72    （能修，重点盯）
```

### 6.4 伪影哨兵

| 哨兵 | 判据 | 实测 |
|---|---|---|
| **对齐 lag（群延迟）** | 正常 < 1 ms；异常 > 5 ms | FIX3 = **6.19 ms**，其他 < 1 ms |
| **MCD** | 相对基准 > 2× | FIX3 = 2.63× |
| **参数步长** | 单轮 ≤ ±20 单位（注意 §3.9 的适用范围） | FIX3 跳了 +53 |
| **输出峰值** | 必须 < **−0.1 dBFS** | 贴着 0.00 本身就是警报——削顶数为 0 只是运气（§10.6） |
