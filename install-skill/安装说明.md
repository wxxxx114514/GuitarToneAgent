# 安装到 skill 目录

## 为什么必须是【目录】不是单个 .md

DSH 支持两种形式（源码 dsh-skill-filesystem）：

| 形式 | 路径 | 能带资源吗 |
|---|---|---|
| 平铺文件 | <root>/<name>.md | **不能** —— 没有自己的目录 |
| **目录 bundle** | <root>/<name>/SKILL.md | 资源放同目录 |

**本 Skill 有 18 份参考文档，必须用 bundle 形式。**
装成平铺文件的话，SKILL.md 里的 reference/xx.md 指针全部解析不了，
等于退化成「没有按需检索的短 Skill」。

## 安装（PowerShell）

```powershell
# 项目级（rank 100，工作区是 <项目根> 时生效）
$dst = '<项目根>\.dsh\skills\guitar-tone-agent'
New-Item -ItemType Directory -Force -Path $dst | Out-Null
Copy-Item -LiteralPath '<本包>\install-skill\guitar-tone-agent\*' -Destination $dst -Recurse -Force

# 校验
$a = (Get-FileHash '<本包>\install-skill\guitar-tone-agent\SKILL.md' -Algorithm SHA256).Hash
$b = (Get-FileHash "$dst\SKILL.md" -Algorithm SHA256).Hash
if ($a -eq $b) { 'OK' } else { '!! 不一致' }
(Get-ChildItem "$dst\reference" -File).Count   # 应该是 15
```

## 第二个 skill：`guitar-tone-manual`（附属）

`guitar-tone-manual` 是**独立的一个 skill**，不是 `guitar-tone-agent` 的子目录 ——
DSH 只扫一层（源码 `dsh-skill-filesystem`：`segments.length === 2 && segments[1] === "SKILL.md"`），
塞进 `guitar-tone-agent\` 里面就**扫不到**了。两个必须平级：

```
<项目根>\.dsh\skills\
├─ guitar-tone-agent\        SKILL.md + reference\（18 份）
└─ guitar-tone-manual\       SKILL.md + reference\  ← 目录联接，指向上面那份
```

### 装法

```powershell
$sk = '<项目根>\.dsh\skills'

# 1) 主体：直接从包里拷（与 install-skill 逐字节一致）
$a = Join-Path $sk 'guitar-tone-agent'
New-Item -ItemType Directory -Force -Path $a | Out-Null
Copy-Item '<本包>\install-skill\guitar-tone-agent\*' -Destination $a -Recurse -Force

# 2) 附属：SKILL.md 单独放，reference\ 用目录联接指过去（零重复、零漂移）
$b = Join-Path $sk 'guitar-tone-manual'
New-Item -ItemType Directory -Force -Path $b | Out-Null
#   把附属 SKILL.md 放到 $b\SKILL.md（现成的一份在 <本包>\install-skill\guitar-tone-manual\）
cmd /c mklink /J "$b\reference" "$a\reference"

# 3) 校验
(Get-ChildItem "$b\reference" -File).Count      # 应为 15
```

> **junction 的代价**：不能跨盘、不能用 git 保存（git 会当普通目录）、需要开发者模式或管理员。
> 它换来的是「方法论只有一份」—— 跑 `sync-skill.ps1` 更新主 skill 时，附属那边**自动**跟着变。
> 不想用 junction，就直接 `Copy-Item` 那 18 份过去，但要记得**两边一起更新**。

## 用户级安装（rank 400）

目标换成 $env:USERPROFILE\.dsh\skills\guitar-tone-agent，其余一样。

## 扫描根与优先级（源码原文）

```
rank 100   <项目根>/.dsh/skills        ★ 项目级（推荐）
rank 200   <项目根>/.agents/skills
rank 300   Config.customSkillDirs
rank 400   <DSH_HOME>/skills           用户级
rank 500   <AGENTS_HOME>/skills
rank 600   bundledSkillDir

项目根 = 含 .git 的最近祖先；没有则用 cwd
扫描深度 = 一层，刻意不支持嵌套 **/SKILL.md
```

> ⚠️ **本包所在的工作区没有 `.git`** —— 按上面这条规则，项目根就等于 DSH 启动时的工作目录。
> 也就是说 `<工作区>\.dsh\skills\` 里的这份**只在 cwd = 那个工作区时才被扫到**；换个目录启动 DSH 就看不到它。
> 要让它永远可用，二选一：
> 1. 给工作区建个 git 仓库（`git init`）—— 顺便也解决改动无历史可查的问题
> 2. 再装一份用户级：`$env:USERPROFILE\.dsh\skills\guitar-tone-agent`（rank 400，不受 cwd 影响）
