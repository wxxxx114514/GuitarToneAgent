## 10. GE250 参数速查

### 10.1 EQ 模块（实测标定）

```
刻度      0 – 100
零点      50（= 0 dB）
量程      ±16 dB
单段增益  32 个单位 = 5.91 dB  →  每单位 0.185 dB
频段宽度  σ ≈ 1.0 倍频程（半高宽 2.32 倍频程）
频段      100Hz / 250Hz / 630Hz / 1.6KHz / 4KHz
换算      数值 = 50 + 目标dB ÷ 0.185
```

**注意**：五段重叠很宽，所以"频段中心处的提升"≠"单段增益"，是 2–3 段叠加。


#### ⭐ EQ 模型标定已验证（含频段重叠）

**两个常数**（多轮实测确认）：
```
1 单位 = 0.1848 dB        （50 = 0 dB，范围 ±16 dB）
σ = 0.985 个八度          （半功率宽度 2.32 个八度）
频段 100 / 250 / 630 / 1.6k / 4k Hz
```

**响应模型**：`gain(f) = Σ_b unit_b × 0.1848 × exp( −(log2(f/f_b))² / (2σ²) )`

**实测验证（FIX5 vs EQFIX2，同一 DI）**：

| 频段 | 施加(单位) | 实测变化(dB) | 模型预测(dB) | 差 |
|---|---|---|---|---|
| 268 Hz | +13 @250 | +1.57 | +2.22 | −0.66 |
| 380 Hz | +13 @250 | +1.59 | +1.96 | −0.37 |
| 3044 Hz | −11 @4k | −2.27 | −2.14 | −0.13 |
| 4305 Hz | −11 @4k | −2.59 | −2.19 | −0.40 |

**模型误差 RMS 0.43 dB，最大 0.66 dB → 可信。**

#### ⚠️ 频段重叠：必须用最小二乘，不能朴素换算

**同一个误差向量，两种算法的结果差很多：**

```
误差: 190Hz −2.21, 268Hz −1.31, 380Hz −2.33, 4305Hz +2.52, 6088Hz +2.31

朴素换算（每个频段独立）:  100Hz +8, 250Hz +12, 630Hz +6, 1.6k −6, 4k −10
最小二乘（考虑重叠）:      100Hz −3, 250Hz +13, 630Hz +1, 1.6k −2, 4k −11
                                  ↑差 11 单位          ↑差 5 单位
```

**原因**：250 Hz 那个 +13 单位，靠 ±1 个八度的带宽已经覆盖了 134–380 Hz，**再动 100 Hz 就过头了**。630 Hz 同理被 250 和 1.6k 夹住。

**照朴素值调会过冲。必须解最小二乘。**

### 10.4 ⚠️ 界面显示的 dB 是 UI 假象（差约 3 倍）★

**GE250 Edit 界面上那排 dB 数字不要拿来算参数。**

```
界面规律:  dB = 数值/2 − 16        （超出 ±16 截顶）
  100Hz=30  →  界面 −1.0
  630Hz=69  →  界面 16.0（真实 18.5，被截顶）
  4KHz=61   →  界面 14.5

真实刻度（界面背后的实际刻度）:
  0.1705 dB/单位，σ = 1.030 八度      （閃光会话独立标定）
  0.1848 dB/单位，σ = 0.985  八度      （本文档 §10.1，BlackShout 会话标定）
```

> **两个标定差 8%，都在同一量级。以 §10.1 的 0.1848 / 0.985 为准**
> （它有 §10.1 的逐点验证，模型误差实测 0.43 dB RMS）。
> 另一个标定的价值是**证明这个刻度跨会话可复现**，不是取代它。

**踩的坑**：看到预设里 `EQ 全 100`、界面显示 `+16.0 dB`，误判成"EQ 被炸了"，
**白跑一整轮**。实际 100 对应的是 +8.5 dB 左右，不是 +16。

> **写死一句：界面上那排数字只用来确认"大概在哪个位置"，不要用来算参数。**

### 10.5 ⚠️ AMP `Mst` 是【线性幅度】控制，不是 dB 控制

```
Mst 55 → 35    实测 −3.15 dB    20·log₁₀(35/55) = −3.92 dB
Mst 35 → 15    实测 −7.02 dB    20·log₁₀(15/35) = −7.37 dB
```

**同样 20 个单位，在不同位置降的 dB 完全不同** ——
**不存在固定的 dB/单位。**

**换算公式**：`ΔdB = 20·log₁₀(新值 / 旧值)`

**适用范围**：音量类参数都这样——`Mst` / `Drive` / `Volume` / `Level`。
**只有 EQ 是 dB 刻度**（1 单位 = 0.1848 dB）。

### 10.6 ⚠️ 整条链的输出恒定贴着 0 dBFS，而且会靠饱和"补"高频

**输出峰值跟发送电平几乎无关**（实测）：

| 发送 | 输出峰值 | 输出 RMS | 削顶样本 |
|---|---|---|---|
| −32 dBFS | **0.00 dBFS** | −13.18 dBFS | **13 个** |
| −38 dBFS | −0.02 dBFS | −14.96 dBFS | 0 个 |

**发送降 6 dB，输出峰值纹丝不动。**

#### 后果一：削顶是常态，不是例外

**输出峰值必须 < −0.1 dBFS。贴着 0.00 本身就是警报——削顶数为 0 只是运气。**
（见 §6.4 哨兵表）

#### 后果二（重要）：输出级在饱和，而饱和会往 6 kHz 补内容

波峰因数（峰值 − RMS）：
```
Mst = 35    14.9 dB    ← 饱和中
Mst = 15    20.7 dB    ← 干净
歌曲吉他轨   17.4 dB    ← 参考
```

**Mst=15 干净之后，6088 Hz 掉了 3.56 dB，误差从 1.52 涨到 1.89。**

> **含义：如果匹配点落在"输出级刚好饱和"上，那个匹配是【脆】的。**
> 它确实测出来更好，但要知道自己是在**靠饱和补高频**——
> 换个演奏力度、换个发送电平，那个补偿就没了。

**行动**：调到一个"不靠饱和"的工作点，再看误差。
如果误差明显变大，说明之前的匹配有一部分是假的。

### 10.7 箱头 / 箱体 / 推子的选择 —— 经典配置（★ 补的是音色的另一半）

> **本文档 §1–§9 全在讲 EQ。但音色有一半由箱头/箱体/推子决定，EQ 只能在这一半之内修。**
> **这一节讲那一半怎么选。**

#### 10.7.1 结论：这半件事靠【经典配置】，不靠搜索

**吉他界几十年的共识就是一张对照表。人也是这么做的：**

```
经典解起手（例：摇滚 = TS808 + JCM900）
  →  靠耳朵微调
  →  调不动了就停
```

**本 Skill 走的是同一条路，只是把「靠耳朵微调」换成了「最小二乘解 + 单轮增益判据」。**
**价值不是比人调得好，是不依赖操作者的经验年限，且结果可复现。**

**⚠️ 不要试图暴力搜索箱头**：GE250 有 **165 个箱头 × 190 个箱体**，
而且换预设必须**手动加载**（实测 USB **不暴露 MIDI 端口**：
`midiOutGetNumDevs()` = 1，那还是系统自带的波表合成器，不是 GE250）。

#### 10.7.2 MNRS 采集分两类（决定链路上要不要开箱体模拟）

| 类型 | 含义 | 链路 |
|---|---|---|
| **Entire 采集** | 箱头 + 箱体 **一体** | 加载后 **不要开 CAB 模块** |
| **Preamp 采集** | 只有前级 | **必须**配 CAB 模块 |

**优先用 Entire**：一次只选一样东西，不会出现「箱头没选错但箱体把它掩盖了」。

> GE300 用户注意：用 Entire 时要在 AMP 模块里**关掉后级模拟**（GE250 无此问题）。

#### 10.7.3 经典配置对照表（从 GE250 实际有的清单里选）

| 音色 | 箱头 | 箱体（若用 Preamp） | 推子 |
|---|---|---|---|
| **摇滚 / 硬摇滚通用** | MARSHALL JCM900 · JCM800 | 4x12 G12T-75 | **TS808 / SD-1** |
| **日系摇滚 / anisong** | MESA MARK V · JP2C · DUAL RECTIFIER | 4x12 V30 | OD（Gain 低 / Level 高） |
| 现代金属 / metalcore | PEAVEY 5150 · EVH 5150 III | 4x12 V30 | OD808 / TS9 |
| djent / 前卫 | 5150 · REVV G20 · DIEZEL VH4 | 4x12 V30 | OD808 |
| 高增益英式 | SOLDANO SLO100 · FRIEDMAN BE100 · ORANGE ROCKERVERB | 4x12 V30 | TS |
| 经典摇滚 | MARSHALL PLEXI 67 · JTM45 | 4x12 Greenback | — |
| 布鲁斯 / clean | FENDER TWIN · DELUXE · BASSMAN | 1x12 Jensen | — |

**实测库存分布**：MESA 22 · MARSHALL 21 · FENDER 12 · BOGNER 8 · SUHR 7 ·
DRIFTWOOD 5 · FRIEDMAN 5 · ORANGE 5 · SOLDANO 5 · VICTORY 5（共 165 个，61 个厂商/系列）

> **⚠️ 同名箱体可能差很多。** `C-4X12 V30 MARSH.gir` 和 `C-CASSA 4x12 SUHR V30.GIR`
> 都叫 V30 4x12，但麦克风位置/房间不同，频谱可能差几个 dB。
> **配置要具体到 IR 文件名，不能只写 V30。**

#### 10.7.4 推子的通用用法（跟箱头同样重要）

```
TS808 / OD808 / SD-1 类：
    Gain  → 0 ~ 低     不加失真，只做过载
    Level → 高          推前级
    Tone  → 中位

效果 = 切低频 + 抬中频  →  让高增益箱头变紧，riff 更清晰
```

**这就是为什么高增益音色几乎都带一个 OD** —— 不是为了加失真，是为了**塑形**。

#### 10.7.5 怎么判断该不该换箱头（唯一硬判据）

> **不问「哪个听着像」，问「哪个在 EQ 优化完之后残差更低」。**

```
EQ 只能改频谱包络。
某个组合在 EQ 拉满后残差仍然大
  →  它的【谐波生成结构】跟目标不对
  →  那正是箱头/箱体的本质区别，EQ 修不了
```

**因为 §10.1 有已验证的 EQ 响应模型（0.43 dB RMS），所以能【软件里预测】最优 EQ 和残差**
—— 每个候选只要 **加载 1 次 + reamp 1 次**，不用真的迭代两轮。

#### 10.7.6 什么时候可以【忽略】这一维

**三条同时成立就该停：**

| 判据 | 实测 |
|---|---|
| **当前残差已到/低于地板** | 閃光：残差 1.49 dB，地板 2.01 dB → 已在地板以下 |
| **地板主要压在低频段**（那是源差异，不是箱头） | 地板主导频段 134/190/268/537/1522/2152 Hz |
| **可能的提升小于听阈** | 人耳阈值实测 ≈0.5 dB（1.77→1.23 用户听不出） |

**参考量级**：箱头模块的贡献约 **1.7 dB**（实测：空音色 3.51 dB → J900R 1.77 dB）。

> **所以：如果换箱头最多只能挤出 0.5 dB 以内，而地板主要在低频 —— 换它没有意义。**
> **这时候正确的做法是停，不是继续。**

#### 10.7.7 操作上怎么选（不需要知道编号）

**设备屏幕上会显示箱头名字**（这也正是 §0.2 那条握手纪律的要求）。

```
① 在设备 UI 里按【名字】选箱头/箱体/推子（不用管 Type 编号）
② 关掉 REVERB / DELAY / MOD，EQ 归平
③ 回读屏幕上是哪个名字（§0.2）
④ reamp 测量
```

**预设 JSON 里是编号**（`effectModule.AMP.Type` / `CAB.Type` / `DS/OD.Type`），
**但逆向编号表没有必要** —— 按名字选、回读确认，比查表可靠。

#### 10.8 调音顺序（7 步，★ 按这个来，不要跳）

> **EQ 是第 5 步，不是第 1 步。** 前面四步定的是**音色本身**，EQ 只在它们之上做整体修正，
> 幅度通常 **3 dB 内**。**先解 EQ、不管箱头和推子 —— 那是在修一个还没定型的音色。**
>
> **⚠️ 这张表是【通用骨架】，不是任何一台设备的参数表。** 每台设备的参数名要对得上 ——
> 例：GE250 的 FXA **参数名由 Type 决定** —— Type 0 是滤波（`Level / Peak / Position / Q`），
> Type 6 是压缩（`Thres / Ratio / Attack / Level`）。同一台设备的同一个模块，换个 Type
> 就是另一套旋钮（真机导出的预设实测）。**照通用措辞去设备上找旋钮，会找不到。**

| 步 | 开什么（其余保持旁通） | 干什么 | 完成判据 |
|---|---|---|---|
| **1** | **AMP + CAB** | 定基础音色：Gain / Bass / Mid / Treble / Presence / Master / 音量 | 这是**核心**，后面所有效果都围绕它。**AMP 那四个音色旋钮在失真前塑形，跟事后 EQ 不是一回事** |
| **2** | FXA | **先看这台设备的 FXA 是什么类**：GE250 是 `Level / Peak / Position / Q`（滤波 / 哇音类）；压缩类才是 Threshold / Ratio / Attack / Release | 调完**别让它改变太大基础音色**（用实测，不用耳朵） |
| **3** | DS/OD | Drive / Level / Tone，配合 AMP 得到主失真或过载 | 当**推子**用时：Drive 小、Level 大、Tone 适中（§10.7.4） |
| **4** | NS GATE | 阈值：刚好压住底噪，**不切断延音和音尾** | 太紧会"咔"一声，太松没效果。（噪声门的位置由设备的链序定，不是你能选的） |
| **5** | **EQ** | 因为它在失真**后**，做的是**整体修正**：先减后加，切掉低频嗡嗡和刺耳高频，再补一点中频 | **幅度通常 3 dB 内**。闭环解 EQ 就是这一步 |
| **6** | FXB → DELAY → REVERB | 顺序：调制类 → 延迟 → 混响。先调干湿比，再调速度 / 深度 / 时间 / 反馈 | 混响放最后，**别盖过干声** |
| **7** | 整体平衡音量 | 逐个开关效果，检查切换时音量跳不跳 | 不忽大忽小 |

**为什么顺序不能换**：第 1–4 步都在**改变信号的谐波结构**，而 EQ **只能改频率响应**。
在 1–4 步没定下来之前解 EQ，解出来的是一组"为了补偿没调好的箱头"的值 —— **箱头一改，全部作废**。

**1–4 步怎么验收（唯一硬判据）**：不看"听着像不像"，看**EQ 拉满之后残差还剩多少**（§10.7.5）。

> **原图里的完成判据全是耳朵的**（"动态平稳但不扁" / "刚好压住底噪" / "别盖过干声"）——
> 那是**从零设计音色**的判据。我们的任务是**复制**，判据必须能测量。
> 耳朵判据只保留在"明显不对"这种粗筛上，**决定性的判据一律是残差**。

```
残差能被 EQ 修掉   ->  1-4 步对了，继续第 5 步
残差修不掉        ->  谐波结构不对，回第 1/3 步换箱头或推子
```

**起点只定三样**：箱头 + 箱体 + 推子，其余模块**全部先关**，然后按上表逐个开。
详见 `08-工作流详解.md` §9.0.5 的「生成起点」。
