## 一、怎么测

### 1.1 ★★ 单模块隔离（M22）—— 测「某个模块的效果」的唯一正确做法

```
① 只开【要测的那一个】模块，其余全关
② 只动【模块开关】，参数保持预设原值
   （要测「参数 -> 效果」时才动参数，而且与「开关」分开做）
③ 「全关」不用录 —— 干参照 = 送出的干音
   ★ 定案（15 §5-2）：**「进设备但全关」那一版【不录】** —— 理由不是「全关≈直通」（实测差 0.408 dB），
     而是：用叠加/统计量判 -> 不用录；用【相减】判 -> 本来必须录（设备本身 +6.9 dB），
     但**相减本轮已证伪（M27）** -> 所以不录。
④ 同一次播放/录音的不同设置版本，必须用【同一个对齐偏移】
```

**为什么**：整条链一起测，测不出单个模块本身；顺手动参数，归因就不清。
★ 这条也是 **H11** 的测法纪律（见 §八）。

### 1.2 ★★ 正交阵列（L9）—— 少次数拿全信息

- **用于**：多个旋钮 + 它们之间的交互项。
- **做法**：三旋钮各取三水平，用 L9 正交表布点（9 次而不是 27 次）；第四旋钮单点补齐。
- **能解出**：主效应 · 交互项 · 全模型残差。
- **本轮实测**：AMP 四旋钮交互项最大 0.044 dB，占主效应 2.43 的 **1.8%** -> 三旋钮基本独立，可连续用；全模型残差 RMS **0.0103 dB**（< σ/7）-> 线性模型够用。

### 1.3 开关对比 / 单点扫描

- 测「某参数单调不单调」：等间隔取 3 点，看跨度是否 > 噪声。
  - 本轮 FXA：Ratio 10/25/50 -> 14.52/11.95/9.46（**单调**）；Thres 40/60/80 -> 13.96/11.95/17.13（**非单调**，60 最压）；Attack 50/80/100 -> 11.61/11.95/11.99（**无效**，跨度 < 0.5）。
  - ★ **注意口径**：上列 Thres40 / Ratio50 是【绝对阈值（−70）】口径；矩阵里同一行是【相对阈值（max−60）】口径（14.181 / 9.461）。**两套不能混** —— 见 08 §5。
- 测「某参数是不是纯电平」：看峰变了多少 **+** 13 段形状变了多少。
  - 本轮 DS/OD Volume：30->10 电平 −2.60 dB，但**形状变化 RMS 0.998 dB** -> 它是**推子**，不是纯电平。

### 1.4 两轨分别分析（M14/M17）—— 先确认素材结构

- **为什么**：参考曲可能是两把不同的琴混在一起，也可能只是立体声同源。
- **怎么**：左右轨分别数 onset + 算 13 段 + 互相关。
- **本轮**：L 267 个 onset · R 621 个 onset · 相关 0.332 · 13 段差 3.16 dB -> **不是同源** -> **只用右轨**。

### 1.5 内容匹配检测（M16/M18）—— 先证明「是同一段」

```
★ 必须先裁空白 + 时长归一，否则会得到假匹配
   本轮：未裁空白相关 0.030 -> 裁空白后 0.482
★ 判据（我定）：> 0.7 同一段 · 0.4~0.7 可用 · < 0.4 重录
★ 反例：我曾用滑窗得到相关 0.939 去推翻用户指定的 9~17s —— 那是假匹配（没做时长归一），被否
★ 口径待定：设计期判过「这条整条是多做的」；但本轮它真的发现了「用户录的那份 DI 对不上 9~17s」
   -> 见 15-设计演化 §5-3
```

### 1.6 尾部留白检查（M31）—— 判「这段素材能不能判混响」

- 混响尾巴只能在「信号结束后的留白」里干净地看。
- 本轮实测：用户弹的 **DI**（目标段）**2.19 s** ✓ · 标定第一段 2.02 s ✓ · **参考曲分轨 9~17s 只有 0.02 s** ✗ · 自造湿声 3.29~3.97 s ✓（留白里有信号）。
- **结论**：目标段（9~17s）只用来定 13 段；**判混响不能在目标段上做**。
- ★ 这条是 **H11** 的前置检查（能不能判，先看留白）。

## 二、怎么对齐（★ 三铁律，我错了三次）

```
① 对齐用【有辨识度段的全范围 FFT 互相关】
   —— 不能假设从 0 开始、不能用 min(len) 截断
② 估增益用【RMS 比】
   —— 逐点最小二乘在微小错位时会崩（实测给过 −28.76 dB）
③ 同一次播放/录音的不同设置版本 -> 必须用【同一个对齐偏移】
   ✗ 每个版本分别对齐 -> 相减时相位对不上（corr 0.025）
   ✓ 统一 lag          -> corr 升到 0.70
```

## 三、怎么判「有没有」（三层门 + 四张图）

### 3.1 三层门（从粗到细）

```
外层：13 段时均 WMAE —— 只管方向，不管细节
内层：5 指标（短时动态 / crest / 峰 / 削顶 / 内容匹配）—— 哨兵，只在越界时报警
波形：削顶 / 断 / 爆 —— 事故级，先于一切
```

### 3.2 四张图各管什么

| 图 | 管什么 | 用在 |
|---|---|---|
| **波形** | 削顶 · 断 · 爆 · 尾巴 | 步 1 / 3 / 9 |
| **频谱（13 段）** | 音色差在哪一段 | 步 0 / 5 / 6 / 7 / 8 |
| **短时动态** | 压缩对不对 | 步 6b |
| **瀑布 / 时间维** | 延迟 · 混响 · 尾巴 | 步 4 |

### 3.3 「有没有」的统计判断（时间维）

```
① 单模块隔离 + 只动开关 —— 否则归因不清
② 判「有没有延迟」：ac@500ms（延迟 +0.28 / 干 −0.12，符号翻转）· 周期性（1.36 / 1.09）
③ 判「是延迟还是混响」：相邻帧跳变中位（延迟 0.84 台阶 · 混响 0.50 平滑）
④ ★ 混合里判不出弱的那个 —— 强的那个主导指纹（本轮延迟比混响强 12 dB）
⑤ ★ 线性要看【能量/统计量】，不看逐点（尾巴是随机相位叠加；本轮能量线性但逐点 corr 只 0.72）
⑥ ★★ **「判」要早 · 「开」要最后**（设计 SOP 原文：「**混响放最后**」）
     判（步 4）必须【早】于解 EQ —— 时基未锁，混响污染 EQ 判读 3.65~8 dB；
     真正【开】周边放到【最后】（EQ 收尾与 NS 之后 = 步 9b），开完不再解 EQ（混响会盖住干声）
```

## 四、怎么定判据

### 4.1 四档来源（★ 每个判据都要能说出自己是哪一档）

| 档 | 含义 | 例子 |
|---|---|---|
| **实测** | 有原始录音 + 脚本可复算 | 内容匹配 0.482 · 窄坑贡献 0.43 dB |
| **换算** | 由实测推出 | 满量程 = 每值单位 × 值域 |
| **我定** | 设计决定（不是从设备测出来的）| 发送电平 −32 dBFS · 削顶定义 · 精度 0.3 dB |
| **⛔待定** | **还没有依据 -> 单列，不许填「合理的数」** | 见 04-判据与来源 |

### 4.2 两条纪律

```
★ 判据要能说出【我在什么条件下失效】—— 说不出的不许用
★ 一个步骤，只有【跳过它会报错】时才算步骤；没有产物、没有验收的「步骤」是愿望
```

### 4.3 依赖设备数值的判据要注明依赖

例：「重复性通过线 σ < 0.1 dB」是**按 GE250 的 σ=0.078 定的**（= 目标精度 0.3 的 1/3）。
换设备后 σ 变了，这条线要**按新 σ 重定**，不能照抄。

## 五、怎么判「够了」

```
★★ 天花板不是 WMAE=0，是【内容差】
   内容差 = 源头 DI 的 13 段 − 目标的 13 段（同一套算法）
   本轮：B2 多 22.04 dB · B13 少 22.95 dB -> 设备改不了
★ 地板 = 内容差本身
★ 停手 = 离地板 ~0.05 dB（本轮 WMAE(不含B2) 3.48 -> 2.85 -> 停）
★ 判据口径：不看绝对值，看「离地板还有多少」
★ 推论：同一个 DI 下比较不同设置（内容差相同）-> 相对改善仍然可信
```

| 工具 | 判什么 | 本轮数值 | 失效条件 |
|---|---|---|---|

## 八、★★ 怎么给一台新设备建尺子（换设备照这个做）

### 8.1 目标

知道「每个旋钮动 1 个单位，13 段各变多少 dB」，以及「这台设备重复性多好」。

### 8.2 顺序

```
H10 两表      ->  先能写预设（模块表 + 参数表：字段名 / 范围 / 枚举）
H7  σ         ->  先知道噪声（后面所有判据都要拿它比）
H4  刻度      ->  EQ 各段刻度 + 对称性 + 叠加性 + 可分性
H1  旋钮      ->  AMP 多旋钮（正交阵列，出主效应 + 交互）
H2  旋钮      ->  CAB 参数
H3  旋钮      ->  FXA 参数（动态 / crest 类）
H11 时间维    ->  DELAY / REVERB 的规律与指纹（单模块隔离 · 三版本）
H5  旁通锚    ->  全模块旁通录一次（上界锚）★ 必须与目标同素材
H8  削顶边界  ->  发送电平扫描（找削顶拐点 / 饱和点）
```

★ **两个口径别混**（见 01-流程 阶段 1 注）：
　实录顺序（本轮）：H10 -> H4 -> H7 -> H1 -> H2 -> H3 -> H11 -> H5 -> H8
　新设备建议：　　H10 -> H7 -> H4 -> H1 -> H2 -> H3 -> H11 -> H5 -> H8
　（H7 提前：H4 的判据「离散 < 噪声」要先有 σ）
★ **硬约束**：**H7 必须在 H1 之前**（H1 的步长与判据都要参考 σ）。
★ 每步有分支：**不满足就停，不许往下走**。

### 8.3 每步的测法 · 判据 · 出处

| 步 | 怎么测 | 判据 | 测法出处 |
|---|---|---|---|
| **H10** | 手册 -> 两表；再用真机导出的预设**核对字段名** | 每个参数都有字段名与范围 | 13-两表规范 |
| **H7** | ★ 三种动作各录几次（见 8.5）| **σ < 精度/3** | ★ 脚本 h7.py / h7b.py（**已提炼**，见 8.5）|
| **H4** | 每段单独 +N / −N 值；再五段同时 +N；与基准同电平相减 | 刻度离散 < 噪声 · 五段可分 · 叠加残差 | ★ 见 8.5（已提炼） |
| **H1** | 三旋钮各三水平（L9）+ 第四旋钮多点；与基准相减 | 交互 >> 主效应 -> 只能离散用；否则可连续用 | ★ 见 8.5（已提炼） |
| **H2** | 每参数扫 5 点 + 一个「零变化对照」；与基准相减 | 跨度 < 噪声 -> 不可用 | ★ 见 8.5（已提炼） |
| **H3** | 四参数各扫 3 点；量短时动态与 crest | 跨度是否 > 噪声 -> 有效/无效 | ★ 见 8.5（已提炼） |
| **H11** | ★ **只开一个模块 · 只动开关（参数保持预设原值）· 三个版本**：① 只开 DELAY ② 只开 REVERB ③ 两个都开 · **全关不用录**（干参照 = 送出的干音）| ★ **指纹：相邻帧跳变中位 0.84（延迟）/ 0.50（混响）· ac@500ms：延迟 +0.28 / 干·混响 −0.12** | 文档摘要 + methods.md M22~M34 + skill素材\12_时间维规律.md |
| **H5** | ★ 四方对比（见 8.5）| **旁通 vs 目标的残差 = 上界锚（★ 必须同素材）** | ★ 脚本 h5_step.py（**已提炼**，见 8.5）|
| **H8** | ★ 发送电平逐档扫（见 8.5）| **削顶样本 > 0 即越界** | ★ 脚本 h8_log.py（**已提炼**，见 8.5）|

★ **13 段的口径**（复现时必须以同一口径）：本轮 A 组脚本（h4_step.py 等）用
　**Nf = 16384 · hop = 8192 · Hann 窗 · 段内功率和 · 转 dB · 跨 13 段去均值**。

```

⑧ 我：报告（先一句话结论，再六项）

```

### 8.5 ★ 八个标定项的测法（从脚本提炼 —— 一手可照做）

> ★ **判断标准**：换设备的人，**只读这一节 + 03-算法，能不能把尺子造出来？**
> 下面每项给 **测什么 / 怎么测 / 判据 / 产物**。这些脚本原本在 `_redo/`（过程脚本，**不在本 skill 里**），
> 所以这里把**做法本身**写下来，不依赖脚本。

**公共前提（所有点都一样）**

```
① 基准 = 一个"差不多"的预设（本轮 presetB）-> 先录一版基准，之后每点都和它比
② 单点操作九步：写预设 -> 用户加载 + 回读 -> 送 -> 录 -> 算 13 段 -> 写矩阵 -> 自检 -> 记账本（见 8.4）
③ 13 段口径必须一致：Nf=16384 · hop=8192 · Hann · 段内功率和 · 去均值
④ 每点都报：峰 / 削顶 / 13 段 / 与基准的差   ★ 必须【同电平相减】，不同电平不能比
⑤ 每点写成矩阵：点,-,B1..B13（一个 CSV，逐点追加）
```

#### H4 · EQ 五段（源：h4_step.py + h4_super.py + h4_sym3.py）

```
测什么：每段动 1 个值单位，13 段各变多少 dB
怎么做（9 个点）：
  基准   : EQ 全 32（= 0 dB）—— 基准录音（本轮 wetH4eq00）
  eq01~05: 五段各自 +10 dB（值 52），逐段录
  eq06   : 100Hz −10 dB（值 12）      <- 用来算对称性
  eq07   : 630Hz −10 dB（值 12）      <- 用来算对称性
  eq08   : 五段【同时】+10 dB          <- 用来算叠加性
每点：与基准相减 -> 一行 13 个数
后处理：
  · 每值单位     = 峰段变化 / 20        （改的是 20 个值单位）
  · 每 1 dB 增益 = 峰段变化 / 10        （每值单位 = 它 x 0.5）
  · 对称性       = RMS( eq01 + eq06 ) · RMS( eq03 + eq07 )      判据：接近 0
  · 叠加性       = RMS( eq08 − Σ(eq01..eq05) )                  判据（我定）：< 0.5 dB
  · 可分性       = 五段两两相关 + 去共线残差                     判据：残差 > σ
★ Mst 另做 4 点（55/45/35/25）
```

- **产物**：`H4响应矩阵.csv`（点,-,B1..B13）· 每值单位 · 对称残差 · 叠加残差 · 两两相关
- **本轮**：每值单位 0.2166~0.2579 · 对称 0.023(630Hz) / 0.734(100Hz) · 叠加残差 **1.259**（-> 不可线性叠加，必须迭代）· Mst「线性」判据**不成立** -> 改查表

#### H1 · AMP 四旋钮（源：h1_step.py + h1_l9.py + h1_pres.py）

```
测什么：三旋钮（Bass/Mid/Treble）的主效应 + 交互项；第四旋钮（Pres）单独做
怎么做：
  L9 正交表布 9 个点（三旋钮各三水平：−20 / 0 / +20 值单位，即 30 / 50 / 70）：
    H1amp00 (-20,-20,-20)   H1amp01 (-20,  0,  0)   H1amp02 (-20,+20,+20)
    H1amp03 (  0,-20,+20)   H1amp04 (  0,  0,-20)   H1amp05 (  0,+20,  0)
    H1amp06 (+20,-20,  0)   H1amp07 (+20,  0,+20)   H1amp08 (+20,+20,-20)
  Pres：H1amp09~12 = Pres 40 / 60 / 70 / 80（单点，与基准相减）
每点：与基准相减 -> 一行 13 个数
后处理：
  · 主效应 = ( mean(该旋钮 +20 的点) − mean(该旋钮 −20 的点) ) / 40     -> dB / 值单位
  · 交互项 = 全模型最小二乘：X = [1, b/20, m/20, t/20, b·m/400, b·t/400, m·t/400]

```

#### H7 · 重复性 σ（源：h7.py · h7b.py）

```
素材：同一预设，四种录音 —— outB1 / outB2（连录）· outB3（切走再切回后）· out_A（对照点，换一个 Mst）

  ② reamp 两次 -> outB1 / outB2
  ③ 逐段差 d = e1 - e2（e = 13 段去均值）-> σ = sqrt(mean(d^2))          <- σ_连录
  ④ 切到别的预设，再加载回基准，回读确认
  ⑤ reamp 一次 -> outB3 -> 同样算 σ（#1 vs #3）                          <- ★ 这一条测「加载可重复」
  ⑥ 跨一次（不同设置）-> 算 σ_跨

同时报：峰值 / 削顶 / 对照点是否更响（Mst100 应比 Mst60 响 > 2 dB，否则要查）
```

## 十、从失败里得到的五条通用教训

```
① 【静态脚印】在「被清理过的分轨」上测不了（尾巴 / 回声被清）—— M2 M5 M9 M11 M12
② 【叠加平均】能增强锁定成分（信噪比 x 根号N），但前提是「事件之间有空隙」—— M9 M11 败在这
③ 【对齐要对到真实事件】而不是理论拍点（演奏有 swing / onset 更真实）—— M8 败、M10 成
④ 【底噪当参照】必须先看它是不是数字零，否则判据没有判别力 —— M12 败
⑤ ★【动态类】可测（音符本身带的信息）·【空间类】难测（被清理清掉）
```
