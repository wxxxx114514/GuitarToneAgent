### 11.0 环境纪律（两条硬规矩）

**① 所有 Python 相关一律走 uv 虚拟环境。** 不要在系统 Python 或现有 venv 里装包。

```powershell
$env:UV_CACHE_DIR = '<包根>\_env\uv_cache'      # 必须设在 workspace 里
$env:UV_PYTHON_INSTALL_DIR = '<包根>\_env\uv_python'
& '<包外>\uv\uv.exe' venv --python '<包外>\py\python.exe' <包根>\_env\<新环境名>
& '<包外>\uv\uv.exe' pip install --python <环境>\Scripts\python.exe <包>
```

**uv 缓存默认在 `%LOCALAPPDATA%\uv\cache`，会被沙箱挡 → 必须设 `UV_CACHE_DIR`。**

**要试新东西就新建一个 venv**，不行直接 `rmdir /s` 删掉，现有环境不受影响。

**② 下载前先问用户切代理**（见 §11.2）。

### 11.0.1 一键重建环境（uv sync）

环境本身**不进版本库**，用两份清单文件复现：

```
pyproject.toml    依赖声明（版本按现有 venv 实测冻结）
uv.lock           锁文件（含各平台 wheel 的哈希）
tools/setup.ps1   一键：uv sync + 下模型 + 自检
tools/dl_bsr.py   模型下载 + sha256 校验（--check 只校验）
```

```powershell
# 一条命令（缺什么补什么）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\setup.ps1

# 等价的手工三步
$env:UV_CACHE_DIR = "$PWD\_env\uv_cache"      # 默认缓存在 %LOCALAPPDATA% 会被沙箱挡
$env:UV_PYTHON    = "$PWD\python\python.exe"  # 用包内解释器；没有就让 uv 下 3.13
uv sync                                        # 建 .venv
python tools/dl_models.py                      # 下模型（699 MB，走 HuggingFace）
```

**为什么环境不进 git**：`venv\` 4.5 GB、`python\` 144 MB、模型 667 MB。
GitHub 单文件上限 100 MB、仓库建议 < 1 GB，所以这些一律 `.gitignore`；
仓库里只留 `pyproject.toml` / `uv.lock` / `models\MANIFEST.json` 这些**能重建出同样环境**的东西。

**已验证（2026-09-29）**：`uv lock` 解析 65 个包；`uv sync` 在约 4.5 GB 的下载后建出环境，
自检 `torch 2.14.0+cu126 / cuda True / numpy 2.5.3 / librosa 1.0.0`，
并用它跑通 `analyze_round.py`（RESULT 0.6585，与包内 venv 的结果完全一致）。
唯一差异：`setuptools` 78.1.0 → 84.0.0（构建工具，不影响运行时）。

⚠️ **不要写 `extra-index-url` 来引入 PyTorch 的 CUDA 源** —— uv 会把它当成所有包的候选，
`certifi` 这类会被它截胡并报 unsatisfiable。正确写法是「默认源 + `explicit = true` 的命名源」
（见 `pyproject.toml` 的 `[tool.uv.index]`），并且用 `environments = ["sys_platform == 'win32'"]` 限定解析范围。

### 11.2 网络

> ⚠️ **下载前必须先问用户切代理。**
> 用户平时挂的是 **AI 网站专用代理**（不影响他日常使用），
> **大文件下载要用另一个专用代理**。
> **任何 >50 MB 的下载，先停下来告诉用户"我要下什么、多大"，等他切好代理再下。**
> 不要占用他的 AI 代理跑下载。


- 沙箱子进程**用不了 Windows 证书库**（`schannel: SEC_E_NO_CREDENTIALS`）→ **Python/uv 用 OpenSSL，能正常工作**
- 本地代理：`http://127.0.0.1:7897`（部分站点需要）
- **大文件下载会中途断（`SSL: UNEXPECTED_EOF`）**→ 用**断点续传**（2MB 分块 + 重试，见 `dl_resume.py`）
- **audio-separator 的模型注册表部分过期**：GitHub 上 404 的模型多半已搬到 **HuggingFace**（`anvuew/dereverb_bs_roformer` 等）
