# 06 · 本次实录（这次音色是怎么一步步调出来的）

> 对象：**MOOER GE250** · 一首歌的吉他音色（目标段 = 参考曲 9~17s）
> 结果：最终预设 **g2eq01** · WMAE(不含B2) **3.48 -> 2.852（地板）** · **用户听感满意** ✓
> 时间：2026-10-08 ~ 09
> ★ 这份是【叙事】—— 每一步「看到什么、怎么决定」。表格版在 01-流程.md；数值与依据在 08-标定值.md。


> ★ **与设备的关系**：这份是 **GE250 那一轮的实录** —— **叙事结构照用**，全部数值换设备重测。
---

## 第 0 段 · 起手：先搞清楚「要比什么」

一开始做的事：**把「参考曲」变成一条可以对数的曲线**。

```
1. 读参考曲。它是立体声，分两轨看：左 267 个 onset · 右 621 个 onset · 左右相关 0.34
   -> 结论：不是双轨同录，是混音过的 -> 只用右轨
2. ★ 一个关键发现：分轨 guitar.wav 的【静音段 = −240 dBFS（数字零）】
   -> 说明这条分轨被【门控/清理】过 —— 混响尾巴被清掉了
   -> 这件事后来决定了「时间维不能从分轨判」
3. 目标段落由【用户指定】= 参考曲 9~17s（不是我自己滑窗挑的）
4. 算出目标的三个数：13 段（去均值）· 短时动态 P95−P50 = 2.03 dB · crest = 12.45 dB
```

**然后做了一件后来最有用的事**：录用户自己弹的参考曲那段（DI），把它和目标**并排**看 —— 结果：

```
★★ 源头 DI 与目标本身就差很大：
     B2（113-160Hz）多 22.04 dB · B13（5.1-7.2k）少 22.95 dB
=> 这就是【内容差】。设备改音色，改不了「弹的是什么、拾音器是什么」。
=> ★ 它意味着：WMAE 永远不可能到 0 —— 有个【地板】。
```

发送信号也在这时造好：把用户弹的那段裁空白、归一化到 **−32 dBFS**、48k/2ch/16bit、前后加静音。

## 第 1 段 · 建「尺子」：A 组标定（★ 每台设备一次）

**想法**：调音之前，得先知道**每个旋钮动一格，13 段各变多少 dB**。不然改参数就是瞎猜。

| 标定 | 怎么做的 | 得出的关键数 |
|---|---|---|
| **H7 重复性** | 同一预设连录、切走再切回、跨一次，各比 13 段 | **σ = 0.078 dB** -> 任何小于 0.1 dB 的差别都是噪声 |
| **H4 EQ 五段** | 每段单独 +20 / −20 单位，看 13 段 | 峰位 B1/B4/B6/B9/B12 · **每值单位 0.2166~0.2579 dB** · 五段叠加**残差 1.259**（-> 不完全线性，要迭代）|
| **H1 AMP 四旋钮** | L9 正交阵列（少次数拿全信息）| Bass 峰B1 **+0.1215** · Mid 峰B6 **+0.0754** · Treble 峰B13 **+0.0744** · Pres 峰B12 **+0.0535** · **交互只占 1.8%**（基本独立）· 拟合残差 0.0103（< σ/7，线性够用）|
| **H2 CAB** | Center 与 Distance 各扫一遍 | Center 峰B13 **+0.0560**（完全线性）· Distance 主要改**整体电平**（10→90 实测 9.61 dB）|
| **H3 FXA 压缩** | Thres/Ratio/Attack/Level 各扫 | Ratio **单调**（−0.11 dB/单位）· Thres **非单调**（60 最压）· **Attack 无效**（跨度 < 0.5）· Level 是**纯输出电平** |

★ 顺序上有一条硬规矩：**H7 必须在 H1 之前**（H1 的步长要参考噪声水平）。

### ★ H11 · 时间维标定（★ 它也是 A 组的一项，不是独立一摊）

**H11 的定位**：它产出的不是「这一首有没有延迟」，而是**判据**（指纹 + ac@500ms）。
　B 组步 4 只是**用它**（见第 2 段）。
★ **做法（三铁律）**：只开一个模块 · 只动开关（参数保持预设原值）· 全关不用录 · **三个版本**。

```
①  h2td01  只开 DELAY     Time=460 · SubD=0 · F.Back=27 · Level=40
②  h2td02  只开 REVERB    Decay=50 · Level=30 · Pre=0 · Tone=40（ROOM）
③  h2td03  DELAY + REVERB 同上

★ 干参照 = 送出的干音（实测：全关 vs 送出 = 13 段差 RMS 0.408 dB）
★ 为什么不录「进设备但全关」那一版：
     「用叠加/统计量」判 -> 不用录；「用相减」判 -> 必须录（设备本身 +6.9 dB）
     而【相减本轮已证伪】（M27）-> 所以不录。   <- ★ 理由是这个，不是「全关≈直通」
```

**测出来**：

| 量 | DELAY | REVERB |
|---|---|---|
| 回声间隔 | ≈ Time 值（460 -> 实测 499 ms）| —— |
| 回声水平（Level=40）| 比直达低 **≈22.5 dB** | —— |
| RT60 | —— | **≈ 1.15 s**（Decay=50）|
| 干路增益（只开一个）| +6.76 dB | +6.97 dB |
| **相邻帧跳变中位** | **0.84 dB**（台阶、有回弹）| **0.50 dB**（平滑）|
| **ac@500ms** | **+0.271** | **−0.134** |
| 周期性 | **1.36** | 1.09 |

**做了三次尝试想「分离混响」，全失败**（都记了档）

```
✗ 相减（两个都开 − 只开延迟）-> 残差 9.2 dB（两次录制的时钟/相位差异消不干净）
✗ 梳状逆滤波拿掉延迟 -> corr 只到 0.22
✗ 回声间隙法 -> 差 +0.1 dB
=> ★ 结论：分开测才行；混合里判不出混响（用户拍板：不做，「延迟真上来混响也听不见」）
```

**还查出一条前提**：判混响要**素材有尾部留白**。
用户弹的有 **2.19 s** ✓ 而**参考曲 9~17s 只有 0.02 s** ✗ -> 所以「时间维不能在目标段上做」。

**两处栽了**：

```
⚠️ H8（削顶边界）：录完用户说那批预设【加载错了】-> 整批作废，要重做
⚠️ H5（旁通锚）：我拿「第一段」的湿声去比「目标段」的目标 -> 跨素材，数字无效
★ 教训：设备上的文件名要能一眼区分批次；每点都要配「核对表」；录完立刻验符号/位置
```

## 第 2 段 · 闭环：B 组 10 步，一轮把音色推到底

规则：**每一轮只让用户加载 1 次**（我算完全部改动，合并成一个预设）。

**起点**：presetB（AMP J800 / CAB 1960 412 / DS-OD 808）· WMAE = 3.48

| 步 | 做了什么 | 看到什么 | 决定 |
|---|---|---|---|
| **0** | 定靶子 + 量本轮的旁通锚 | — | — |
| **1** | 查事故（削顶/断/爆）| 没有 | 过 |
| **2** | ★ 存在性：设备上真的是这个预设吗 | 无回读通道 -> **让用户回读屏幕** | 过 |
| **3** | 回录峰值 / 电平 | 削顶 = 0；峰 −8.48 vs 目标 −1.79（差 −6.70）| **不动音色链**，用回录侧音量补 |
| **4** | 时间维（DELAY/REVERB）| ★ **用 H11 的判据**判参考曲 -> **判不了**（分轨被清理 + 目标段无留白）| **Bypass + N/A + 试开试关 + 用户听** |
| **5** | 算窄度 | 窄坑只贡献 **0.43 dB**（原始 3.48 -> 平滑后 3.05）| **跳过步 7** |
| **6** | **宽带**：AMP 的 Bass/Mid/Treble/Pres | ★ 三个解法（成片均值 / 逐旋钮独立解 / 峰值段法）**全都不如不动** | **只做温和一步：Bass 50->34 / Mid 30->70** -> 2.979 |
| **6b** | 压缩（FXA）| H3 显示最小的那档也压掉 44% | **不开 FXA**（差 0.83 dB）|
| **7** | 窄坑 | 已判不重要 | **跳过** |
| **8** | **EQ 收尾** | 五段微调；实测幅度 < 标定预期（叠加非线性）| g2eq00 2.974 -> **g2eq01 2.852** |
| **9** | NS GATE | 底噪 −91 dBFS 已经够低 | **Bypass** |
| **10** | **停手** | 离地板只剩 ~0.05 dB | 停 |

**途中换过的一次关键选择：CAB 的 Mic**

```
Step0 试了 SM57 / U47 / U87：
  U87 = 起点（3.480，交叉验证用）· U47 = 4.274 · **SM57 = 3.027**
=> 选 SM57 ✓（一次就定了，且它是「起点预设本来没想到」的收益）
★ 副作用发现：换 Mic 会显著改动态（0.53 -> 2.66）—— 因为频响变则失真程度变
```

**最终预设 g2eq01**

```
AMP   J800  Gain50 / Bass34 / Mid70 / Treble40 / Pres50 / Mst100
CAB   1960 412  Tube EL34 / Mic SM57 / Center30 / Distance25 / Sync ON / Level50
DS/OD 808  Volume30 / Tone85 / Gain65
EQ    ON  100Hz30 / 250Hz28 / 630Hz32 / 1.6KHz29 / 4KHz30 / Level50
FXA / FXB / NS GATE / DELAY / REVERB  全关
```

**WMAE(不含B2)：3.48 -> 2.852**，动态 3.06（目标 2.03），crest 13.15（目标 12.45）。**用户听后：满意** ✓

### 步 8 的「效应分离」（三个点，值得记）

| 点 | 设定 | WMAE(不含B2) | 说明 |
|---|---|---|---|
| A g1amp01 | EQ **关** | 2.979 | 步 6 结果 |
| B g2eq00 | EQ **开 · 全 32** | 2.974 | ★ 对照点 |
| C g2eq01 | EQ 开 · 带设定 | **2.852** | 步 8 结果 |

```
① 【开 EQ 本身】B − A = 形状 RMS 0.011 dB   -> 可忽略
② 【EQ 设定的影响】C − B = 形状 RMS 0.277 dB -> WMAE 改善 +0.123 dB
★★ 实测幅度 < 标定预期（B1 预期 −0.52 / 实测 −0.02）
   —— 因为 H4 标定是「单独动一段」，现在是「五段同时动」-> 叠加非线性（残差 1.259）在起作用
```

## 第 3 段 · 这一轮到底学到了什么（最要紧的几条）

```
① ★★ 天花板不是 WMAE=0，是【内容差】。先量内容差 -> 知道地板 -> 追到离地板 ~0.05 dB 就停
② ★ AMP 的宽带旋钮「动一个会拖别的」-> 它只能修整体倾斜，修不了零散单段；三个解法都不如不动
③ ★ EQ 实测幅度小于标定预期 -> 那是 H4 已测到的叠加非线性在起作用
④ ★ 顺序铁律：1 最前 · 2 是门 · 4 在 8 前 · 7 在 8 前（都是计算顺序）
⑤ ★ 判定在最后 —— 用户听。我们前面的数都是「传感器」，不是判决
⑥ ★ 从参考曲分轨判时间维：原理上不可能（分轨被门控清理过，静音段 −240 dBFS）
   —— 但那是【素材】的问题，不是方法的：在自造湿声上（H11）同样的统计量立刻可用
```

## 第 4 段 · 如果重跑一遍，我会怎么做（更省的路）

```
1. 先把「内容差」量出来（半天的活）-> 直接知道地板在哪，不用追到最后才发现
2. 起点预设先试 CAB.Mic（SM57 那一步就是白赚的 0.45 dB）
3. AMP 宽带那步：直接用「温和一步」，不要试三种解法（三种都不如不动，白花时间）
4. 窄坑先量贡献（0.43 dB < 0.5）-> 直接跳过，不用试
5. H11 时间维一开始就分开测（只开一个模块），不要在混合里折腾
6. 每个加载点都配「核对表 + 录完验符号」（H8 那次就是这么废掉的）
```
