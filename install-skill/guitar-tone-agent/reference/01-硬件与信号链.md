## 1. 硬件与信号链

```
电脑 ──USB──> GE250 ──效果链──> 模拟输出（监听）
     <──USB──  回传（录音）
```

### 1.1 设备端点（Windows / WinMM）

脚本按名字里的 `MOOER` 子串自动查找，**不依赖索引**（索引会变）。

```
输入:  线路 (MOOER STUDIO)          或  线路 (2- MOOER STUDIO)
输出:  扬声器 (MOOER STUDIO)        或  扬声器 (2- MOOER STUDIO)
```

**`2-` 前缀**是 Windows 对"插在不同 USB 口"的命名差异，两种都要能匹配。

### 1.2 GE250 的 USB AUDIO 设置（上位机 SYSTEM 页）

| 项 | 必须的值 | 说明 |
|---|---|---|
| **AUDIO MODE** | **REAMP** | NORMAL 模式下回传收不到效果链输出 |
| LEFT OUT / RIGHT OUT | DRY / DRY（锁死，改不了） | 不影响录音 |
| REC VOL / MIX / PLAY VOL | 50 / 50 / 50 | 先别动，回环通了再看电平 |

**断电会重置这些设置。** 每次设备断电后必须重新确认 AUDIO MODE = REAMP，并**在软件里点一下 NORMAL 再点回 REAMP**（强制重新下发，因为软件显示的状态可能和设备实际状态不同步）。

### 1.3 设备物理属性（实测，跨断电可复现）

| 属性 | 值 | 怎么测的 |
|---|---|---|
| 实时比 | **1.000×** | 10.000 s 音频 → 10.006 s 墙钟 |
| 确定性 | 0.008 dB RMS / 0.022 dB max | 两次相同渲染的频谱差 |
| 固定增益（**空音色**） | **+5.3 dB** | DI 峰值 → 湿声峰值 |
| 固定增益（**高增益音色**） | **约 +32 dB** | 发送 −32 dBFS → 输出 0.00 dBFS（见 §10.6） |
| 往返延迟 | 100–250 ms（会变） | 每次测量都要重新对齐 |
| 压缩比（失真预设） | **约 5:1** | 12 dB 输入 → 2.4 dB 输出 |
| 动态范围 | 失真下几乎不变（12 dB 输入只改频谱 0.3–0.44 dB） | 三档电平测试 |

**实时比 1.000× 是硬约束**：1 次渲染 = 音频时长 + 预设加载（~2 s）。单台设备不能并行。

> **⚠️ 增益随音色变化极大（+5.3 → +32 dB，差 27 dB）。**
> 照 §4.3 的「−30 ~ −35 dBFS」选电平，在空音色下没问题，
> **在高增益音色下必然削顶。** 每次换音色都要重新标定输出峰值（§10.6）。
