# presets\ —— 设备预设目录

这个目录的用途只有一个：**放设备（GE250）导出的预设文件**，也就是 `preset_format.template`
（`devices\<型号>\parameter_table.json` 里那一块）的来源。

## 它【不是】起点预设的来源

起点预设由 `synth_start.py` 从**设备规格表 + §10.7.3 经典配置**组出来，
每个值要么来自说明书默认值、要么来自经典配置 —— **不抄现成预设**。
理由：抄一份现成的 = 把厂商（或上一轮）的审美当起点，而且会让 agent 走捷径。

## history\ 是什么

过去几轮调音留下的产物（`EQFIX2` / `FIX4` / `FIX5` / `J900RG` / `CSFIX*`）。
它们的价值是**历史记录**，不是可照抄的参数值：
同一份预设只在**它自己那首歌**上有意义，换歌作废。

（没有按歌分目录，是因为这几份未必都属于同一首歌 —— 与其编一个归属，不如如实标成历史产物。）
