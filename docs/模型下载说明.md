# 分轨模型怎么下载

> BS-Roformer SW 6-stem —— 6 轨分离（人声/贝斯/鼓/吉他/钢琴/其他）

## 一句话

从 HuggingFace 的 Blakus/bs_roformer_sw_6stem 下两个文件，放进 models/。

```
仓库   https://huggingface.co/Blakus/bs_roformer_sw_6stem
commit dd755f5f5eaa1b01deb970fb296a55f6fec458a6

BS-Rofo-SW-Fixed.ckpt    699,412,152 字节   699 MB
BS-Rofo-SW-Fixed.yaml          4,852 字节   4.9 KB
```

## 方法一：跑脚本（推荐）

```bat
cd <包目录>
venv\Scripts\python.exe tools\dl_bsr.py
```

它会下到 models/，并用 sha256 逐个校验。

## 方法二：手动下

两个 URL（浏览器直接开也行，记得挂代理）：

```
https://huggingface.co/Blakus/bs_roformer_sw_6stem/resolve/main/BS-Rofo-SW-Fixed.ckpt
https://huggingface.co/Blakus/bs_roformer_sw_6stem/resolve/main/BS-Rofo-SW-Fixed.yaml
```

下完放进 models/，**文件名不要改**。

## 校验（重要）

```powershell
Get-FileHash 'models\BS-Rofo-SW-Fixed.ckpt' -Algorithm SHA256
# 应为 24E7D35EE9C64415673D3FD33E06A67CAC2C103C5DF6267BA1576459C775916E

Get-FileHash 'models\BS-Rofo-SW-Fixed.yaml' -Algorithm SHA256
# 应为 E17A3B4BAC1B924BCB521F569DCBF8B0318C23EFFEC026DE81EB95351B5FC8AF
```

## 三个坑（都真踩过）

### 一、直连不通，要走代理

```
HF 的 API 可以直连，但【文件下载】经常被掐（连接被重置）。
实测：直连失败，走 http://127.0.0.1:7897 成功。
```

脚本会自动在【直连 / 代理】之间切换。手动下的话，浏览器挂代理就行。

### 二、.yaml 没有 Content-Length

```
ckpt  HEAD  ->  Content-Length: 699412152   有
yaml  HEAD  ->  Content-Length: (空)         没有！
```

所以**不能靠「下了多少字节」判断完整性**，必须用 sha256。
（用 requests.get 直接取，别指望 Content-Length。）

### 三、大文件连接会中途断

699 MB 一次拉完经常断。脚本用的是**分段 Range 请求**（每次 2 MB + 40 次重试），
断了从断点续，不重头来。

## 模型为什么必须「运行时注册」

**这个模型不在 audio-separator 的官方注册表里。** 加载前要先塞进去：

```python
from audio_separator.separator import Separator

_orig = Separator.list_supported_model_files
def patched(self):
    d = _orig(self)
    d.setdefault("MDXC", {})["Roformer Model: BS-Roformer SW 6-stem (local)"] = {
        "filename": "BS-Rofo-SW-Fixed.ckpt",
        "scores": {},
        "stems": ["vocals","bass","drums","guitar","piano","other"],
        "download_files": ["BS-Rofo-SW-Fixed.ckpt", "BS-Rofo-SW-Fixed.yaml"],
    }
    return d
Separator.list_supported_model_files = patched

sep = Separator(model_file_dir="models", output_dir="out", output_format="WAV")
sep.load_model(model_filename="BS-Rofo-SW-Fixed.ckpt")
```

**为什么能行**：库里的 download_file_if_not_exists() 会**先看文件在不在**，
在就跳过下载直接加载。所以只要文件摆在 model_file_dir 里，注册表补个条目就够。
