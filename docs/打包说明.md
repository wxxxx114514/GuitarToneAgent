# 交付包说明

## 结构

| 路径 | 内容 |
|---|---|
| **`SKILL.md`** | **指令文档（4.5 KB / 86 行）** —— 每次加载的就是这份，只放铁律 + 工作流 + 索引 |
| `reference/` | **参考资料（14 份）** —— 按需读，**不常驻上下文** |
| `tools/` | 29 个 Python 脚本（含 2 个回归套件）+ 3 个 ps1 / 1 个 cs |
| `models/` | BS-Roformer 6 轨分离模型（667 MB） |
| `ffmpeg/` `python/` `venv/` | 自带环境，拷走即用 |
| `presets/` | 放**设备导出的预设文件**（拿它的结构）+ `history/` 历史产物；★ 不是起点预设的来源 |
| `songs/` | 每首歌的工作目录 |
| `install-skill/` | 装到 DSH 用的那份 + 安装说明 |

## 为什么 SKILL.md 这么短

**Skill 是【指令文档】，不是【知识库】。**

拆分前：`SKILL-完整版.md` 2036 行 / 49657 字符 ≈ 15k token，每次加载全灌进来，其中九成是参考资料。
拆分后：86 行 / 2271 字符 ≈ 700 token，**缩小 20 倍以上**。

详细的领域资料放在 `reference/`（14 份），**agent 遇到具体问题时才去读那一份**。

`models/` 和 `ffmpeg/` 用的是硬链接（指向原位置）。
