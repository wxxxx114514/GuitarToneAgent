# 这两份是什么关系

| 文件 | 大小 | 用途 |
|---|---|---|
| `../SKILL.md` | 4.5 KB / 86 行 | **精简指令版** —— 日常加载，铁律 + 工作流 + 索引 |
| `SKILL-完整版.md` | 86.7 KB / 2036 行 | **完整版** —— 全部细节，用于测试/查阅 |

## 为什么两个都留

**精简版**：Skill 是【指令文档】，不是【知识库】。每次对话加载 4.5 KB 而不是 87 KB，
省下约 15k token。详细资料按需从 `reference/` 读。

**完整版**：为了对照测试 ——

```
测试目的：验证「50 KB 的 Skill 到底能不能用、好不好用」

对照组 A  加载 SKILL-完整版.md    48 KB 一次性灌入
对照组 B  加载 SKILL.md + 按需读 reference/   4.5 KB + 按需

对比：agent 表现 / 上下文占用 / 是否漏掉关键规则
```
