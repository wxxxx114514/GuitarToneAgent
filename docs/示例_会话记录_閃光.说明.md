# 这份文件是什么

`示例_会话记录_閃光.md` —— **另一首歌（閃光 English Version / [Alexandros]）的完整会话记录**，
是 `SKILL.md` §9.5「会话记录格式」的真实范例。

## 为什么值得留着

**它跟 BlackShout 是两个会话、两首不同的歌**（閃光 = C# 大调，BlackShout = E），
**却独立得出了完全相同的 9 条结论**：

| 结论 | 閃光 | Skill |
|---|---|---|
| 界面 dB 是 UI 假象 | 0.5 dB/单位 vs 真实 0.17 | §10.4 |
| Mst 是线性幅度 | 55→35 掉 3.15 dB | §10.5 |
| 预设没加载 ≠ 设备非线性 | RV3 未加载 → 两次测量全等 | §0.2 |
| 对齐窗口 ±60 ms 太窄 | lag 撞边界 → 相关 0.002 | §4.4 |
| 分轨掐混响尾巴 | −240 dB 全零 | §3.15 |
| 全曲 chroma 抹平调性 | 要按半小节分段 | §13.1 |
| 单轮增益塌缩才算收敛 | −0.09 → 收敛 | §9.2 |
| 预设名长度限制 | 9 字符读不进去 | §2.2 |
| 合成 DI 不可当依据 | 压根没用合成 DI | §9.1 |

**这说明方法论不是过拟合到某一首歌上。**
